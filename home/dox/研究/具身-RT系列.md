# RT 系列：从视觉语言到机器人动作
## 1. 路线演进
<font color='#2aa198'>RT-1</font> 将图像和语言映射到机器人动作 token，重点是多任务数据和动作离散化；<font color='#d33682'>RT-2</font> 进一步引入互联网视觉语言知识，使策略具备更强的语义和组合泛化。后续工作持续扩展模型规模、动作表示、机器人数量和长程任务能力。

## 2. 动作表示
连续动作可离散化为 bins，也可由扩散策略或 flow matching 直接生成。离散 token 易于与语言模型整合、训练稳定且部署简单，但量化误差会影响精细抓取；连续生成更平滑，却需要处理采样步数、噪声调度和实时性。

## 3. 复现要点
保持图像裁剪、归一化、相机外参、动作频率和 token 映射一致；记录动作范围、bin 数、特殊 token、夹爪编码和终止规则。评测要区分 seen/unseen 物体、不同初始位姿、遮挡和失败恢复，避免只展示最优轨迹。

## 4. 训练细节
训练阶段监控行为克隆损失、动作重建误差、token 熵和验证集成功率。对离散策略，检查高频动作是否集中在少数 bins；对连续策略，检查动作速度、加速度和 jerk，防止策略虽然成功但不适合真实执行器。

## 5. 部署建议
使用固定长度动作窗口和实时状态检查。检测到目标偏移、抓取失败或视觉置信度过低时立即停止当前 chunk，重新拍摄并调用高层策略重新规划。部署日志应保存观测、动作、模型置信度和中断原因。
