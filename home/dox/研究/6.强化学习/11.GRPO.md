# GRPO：用同题多答替代价值基线

## 1. 时间与方法全称

**组相对策略优化（Group Relative Policy Optimization，GRPO）**在 **2024 年 2 月**《DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models》中提出。它用同一问题下多条回答的相对奖励构造优势，省去 PPO 中单独训练的价值模型。

2025 年 DeepSeek-R1 扩大了这一方法的影响，但不是 GRPO 的首次提出时间。下文以 DeepSeekMath 的 outcome-supervision 版本为主，不混入后续所有无 KL、改归一化等变体。

## 2. 核心思想

![GRPO组相对优势](/rl-grpo-1.png)

对一个问题生成一组答案，在组内比较谁更好。这个组提供相对基线：高于平均奖励的回答获得正优势，低于平均的获得负优势；同一回答的 token 共享结果级优势。

省去 critic 不等于省去评价器。奖励可来自规则验证器，也可来自学习得到的奖励模型，其错误会直接进入策略更新。

## 3. 优势定义与符号

$$
\mu_r=\frac1G\sum_{i=1}^G r_i,\qquad
\sigma_r=\sqrt{\frac1G\sum_{i=1}^G(r_i-\mu_r)^2},\qquad
\hat A_{i,t}=\hat A_i=\frac{r_i-\mu_r}{\sigma_r}.
$$

这里明确采用总体标准差，便于复现算例；原文写 mean/std，实际代码还需核对分母 G 或 G−1。σr=0 时原式未定义，工程上可跳过无区分度组或使用小常数稳定，并保证分子为零时不产生 NaN。这是实现补充，不应悄悄归入原式。

| 符号 | 含义 |
| --- | --- |
| q、oᵢ | 问题、第 i 条回答 |
| G、Tᵢ | 同题回答数量、回答有效 token 长度 |
| ri、μr、σr | 结果奖励、组均值、组标准差 |
| πθ、πold | 当前模型、生成本组回答的冻结旧模型 |
| πref | 用于正则的固定参考模型，不等于每轮刷新的旧模型 |
| ε、β | 裁剪半宽、KL 正则系数 |
| ρi,t、Âi,t | 给定前缀的 token 概率比、token 所用优势 |

## 4. DeepSeekMath 原始目标

$$
\rho_{i,t}=\frac{\pi_\theta(o_{i,t}\mid q,o_{i,<t})}{\pi_{\mathrm{old}}(o_{i,t}\mid q,o_{i,<t})}.
$$

最大化以下组平均、回答内 token 平均目标：

$$
\mathcal J_{\mathrm{GRPO}}=\mathbb E_{q,\{o_i\}\sim\pi_{\mathrm{old}}}\left[\frac1G\sum_{i=1}^G\frac1{T_i}\sum_{t=1}^{T_i}\left\{\min\!\left(\rho_{i,t}\hat A_i,\operatorname{clip}(\rho_{i,t},1-\epsilon,1+\epsilon)\hat A_i\right)-\beta k_{i,t}\right\}\right].
$$

原文使用的非负单样本 KL 估计项为：

$$
u_{i,t}=\frac{\pi_{\mathrm{ref}}(o_{i,t}\mid q,o_{i,<t})}{\pi_\theta(o_{i,t}\mid q,o_{i,<t})},\qquad
k_{i,t}=u_{i,t}-\log u_{i,t}-1.
$$

对固定前缀，若 token 按当前 πθ 采样，且支持条件满足，则 Eπθ[k]=DKL(πθ∥πref)。本轮数据实际来自 πold；多轮更新后，这个样本平均不能无条件称为当前分布 KL 的无偏估计。非负性来自 u−logu−1≥0，不等于估计已经精确。

## 5. 网络与训练流程

![GRPO训练结构](/rl-grpo-2.png)

语言模型输出下一个 token 的分布；旧模型生成 G 条回答，评价器给出奖励。当前模型计算 token log 概率，参考模型计算 KL 相关分数。优势和旧概率冻结，梯度通过当前模型。

相比 PPO，GRPO 去掉独立 V 模型；与 DPO 不同，它通常持续从更新中的策略收集回答并评分。结果监督中同一回答共享优势，无法单凭这个标量确定某个推理步骤的独立贡献。原文还讨论过程监督，不能把它与结果监督的优势定义混用。

## 6. 优缺点与失败机制

![GRPO优缺点](/rl-grpo-3.png)

它减少价值模型的训练与存储开销，适合有可靠可验证奖励的任务。代价是同题多次生成，且全部答对或全部答错时没有组内相对信号。增加 G 有时能获得混合成功组，但不能保证发现模型完全不会的解法。

按问题标准差缩放会改变不同问题的梯度权重；按回答长度平均也会影响不同长度样本的贡献。这些是目标设计的一部分，不是纯粹无影响的单位变换。还需警惕奖励漏洞、重复答案和模板投机。

## 7. 算例与检查

奖励 (1,1,0,0) 时，μr=0.5、σr=0.5，优势为 (1,1,−1,−1)。若奖励全为 0，稳定实现可将整组优势置零，但这只避免数值错误，不会产生新的正向学习信号。

冻结同一批回答检查新旧策略相同时 ρ=1；若当前模型等于参考，k=0。记录组奖励方差、无效组比例、回答长度、KL、clip fraction 与独立 pass 指标；pass@k 与 pass@1 不应混报。
