# Q-Learning：从采样转移学习最优动作价值

## 1. 时间与方法全称

**Q-Learning（Q 学习）**由 Watkins 在 **1989 年博士论文**中提出；Watkins 与 Dayan 于 **1992 年**发表经典收敛论证。Q 是动作价值函数的惯用符号，不应杜撰成一个未在论文定义的英文缩写。

它是无模型、离策略的时序差分控制方法：可以用探索策略收集的转移，学习以贪心动作继续行动的最优价值。表格 Q-Learning 不包含神经网络；DQN 才把表示扩展为深度网络。

## 2. 核心思想

![QLearning价值传播](/rl-qlearning-1.png)

每次经历一步转移，就把当前动作价值向“即时奖励加下一状态最好价值”移动一点。终点奖励通过多次备份向更早状态传播，无需等每条轨迹都结束。

“离策略”体现在备份中的 max：即使下一动作实际上出于探索选了较差动作，目标仍使用下一状态的最大 Q。SARSA 则使用实际采样的下一动作价值，二者的学习目标不同。

## 3. 原始更新式与完整符号

Watkins–Dayan 论文的核心异步更新可写为：

$$
Q_{t+1}(s_t,a_t)=Q_t(s_t,a_t)+\alpha_t\left[r_t+\gamma(1-d_t)\max_{a'}Q_t(s_{t+1},a')-Q_t(s_t,a_t)\right].
$$

未访问的表格单元保持不变。等价地，新值是旧值与目标的凸组合，前提是 αₜ∈[0,1]。

| 符号 | 说明 |
| --- | --- |
| Qₜ(s,a) | 第 t 次更新之前的动作价值表，不是概率 |
| sₜ、aₜ、sₜ₊₁ | 本次转移的起点状态、执行动作、后继状态 |
| rₜ | 执行动作后收到的即时奖励 |
| αₜ | 当前状态动作对的学习步长；收敛条件按每个单元统计 |
| γ | 折扣因子，折扣无限时域通常小于 1 |
| dₜ | 真正终止指示量，终止时后续价值取零 |
| a′ | 在下一状态枚举的合法候选动作 |
| δₜ | 方括号内的 TD 误差，正值表示当前估计低于采样目标 |

原论文使用吸收终止状态；这里显式增加 dₜ 是等价的常见实现写法。

## 4. 行为策略与计算流程

![QLearning更新流程](/rl-qlearning-2.png)

ε-greedy 可以定义为：以概率 ε 从合法动作均匀采样，以概率 1−ε 从最大 Q 动作集合选择。若有多个并列最大动作，必须说明打破平局的规则。

$$
\pi_{\mathrm{greedy}}(s)\in\operatorname*{arg\,max}_a Q(s,a).
$$

训练循环是读取状态、选动作、交互、构造目标、更新单元，再进入下一状态。无需拟合转移概率，但仍需要足够的数据覆盖。ε=0 过早会停止探索；固定 ε 的行为策略不是最终部署时常用的纯贪心策略。

## 5. 目标、随机逼近与收敛前提

固定点是 Bellman 最优方程：

$$
Q^*(s,a)=\mathbb E\left[r+\gamma\max_{a'}Q^*(s',a')\mid s,a\right].
$$

Q-Learning 的样本目标是对右侧期望的一次随机观测，而不是对整个 Bellman 残差做全梯度下降。表格情形的经典几乎必然收敛结论需要有限状态动作、适当奖励条件、充分访问，以及每个状态动作对的步长满足：

$$
\sum_{k=1}^{\infty}\alpha_k(s,a)=\infty,\qquad
\sum_{k=1}^{\infty}\alpha_k(s,a)^2<\infty.
$$

k 是该单元被更新的次数。αₖ=1/k 满足典型条件；恒定步长适合追踪变化，但不满足这一精确收敛定理。环境非平稳、函数逼近或覆盖缺失都需要另行分析。

## 6. 优缺点与典型失败

![QLearning优缺点](/rl-qlearning-3.png)

优点是更新简单、不需转移模型，并有清晰的表格理论。局限是高维状态无法枚举，连续动作的 max 可能困难，且对带噪估计取最大会产生过估计倾向。

Double Q-Learning 将动作选择与价值评价部分分离，以缓解选择偏差；这不是把同一 Q 表计算两次。离线固定数据上直接做 max 还可能选择从未出现的动作，对应后续 IQL 关注的数据外推问题。

## 7. 算例与实现检查

Q(s,a)=2、r=1、γ=0.9、下一状态最大 Q=4、α=0.1，目标为 4.6，TD 误差为 2.6，新值为 2.26。若该转移真正终止，目标改为 1，新值为 1.9。

检查动作掩码是否同时用于探索和 max，是否误把时间截断当作终止，是否每次只更新访问单元。不要用训练奖励上升替代独立评估，也不要把表格定理表述为“所有 Q 网络必然收敛”。
