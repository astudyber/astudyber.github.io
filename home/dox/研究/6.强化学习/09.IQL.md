# IQL：只用数据内动作完成隐式策略改进

## 1. 时间、全称与缩写辨析

**隐式 Q 学习（Implicit Q-Learning，IQL）**由 Kostrikov、Nair、Levine 于 **2021 年 10 月**公开，发表于 ICLR 2022。本文不是多智能体领域的 Independent Q-Learning，也不是分位数网络 IQN。

离线 RL 不能随时访问环境验证新动作。直接 max Q 或查询新 actor 产生的动作，可能利用数据外虚高 Q。IQL 在价值学习时只查询数据动作，再通过优势加权行为克隆提取策略。

## 2. 核心思想

![IQL核心思想](/rl-iql-1.png)

同一状态的行为数据可能包含好坏不同的动作。普通均方回归估计平均 Q；不对称平方误差则让 V 更靠近较高 Q，而不必显式枚举未见动作。随后用 V(s′) 构造 Q 目标，让较好行为的价值沿轨迹传播。

这种“隐式改进”发生在状态条件的数据动作分布中，不是对全部动作空间无约束取最大。离线数据的覆盖与连通性仍然决定可学到的行为范围。

## 3. Expectile 损失与符号

原论文的核心是不对称平方损失：

$$
L_2^\tau(u)=\left|\tau-\mathbf1\{u<0\}\right|u^2,\qquad
\mathcal L_V(\psi)=\mathbb E_{(s,a)\sim\mathcal D}\left[L_2^\tau\big(Q_{\bar\phi}(s,a)-V_\psi(s)\big)\right].
$$

τ=0.5 时是普通均方误差的常数倍；τ>0.5 时低估较高 Q 的代价更大，拟合得到上 expectile。**Expectile（期望分位）**由不对称平方误差定义，**quantile（分位数）**由不对称绝对误差定义，二者不能互换。

| 符号 | 说明 |
| --- | --- |
| D | 固定的离线转移数据集 |
| φ、φ̄ | critic 参数与延迟更新的目标 critic 参数 |
| ψ、θ | 状态价值 V、策略 π 的参数 |
| τ | expectile 非对称系数，通常取 0.5<τ<1 |
| u | Q−V 残差；正残差权重 τ，负残差权重 1−τ |
| γ、d | 折扣与真正终止指示量 |
| β | 本文采用原文常见的优势指数乘数，即逆温度 |
| sg | 停止梯度；被回归的 Q、V 与策略权重应按各损失分开处理 |

## 4. 三个组件与三个目标

![IQL网络与损失](/rl-iql-2.png)

图中 TD 目标展示非终止转移；完整实现必须使用下式的 (1−d) 掩码。图中的 Q 目标输入对应延迟更新的目标 critic，拟合 V 时不沿它反传。

Q 网络读取 (s,a) 输出标量，V 网络只读取 s，actor 读取 s 输出数据动作的概率分布。常见连续控制配置用 MLP 与高斯 actor；双 Q 实现可取目标 Q 的最小值来缓解高估，须注明这是具体实现。

$$
\mathcal L_Q(\phi)=\mathbb E_{(s,a,r,s',d)\sim\mathcal D}\left[\big(r+\gamma(1-d)V_\psi(s')-Q_\phi(s,a)\big)^2\right].
$$

这个损失更新 Q，右侧 V 目标停止梯度。策略提取使用优势加权回归：

$$
A(s,a)=Q_{\bar\phi}(s,a)-V_\psi(s),\qquad
\mathcal L_\pi(\theta)=-\mathbb E_{(s,a)\sim\mathcal D}\left[\operatorname{sg}\!\left(e^{\beta A(s,a)}\right)\log\pi_\theta(a\mid s)\right].
$$

β 越大，权重越集中于高优势动作；若另一个实现写 exp(A/β)，其 β 是温度，方向相反。实践常给权重设上限以控制方差，这会改变精确权重，需在实验中说明。

## 5. “不查询数据外动作”的准确含义

价值训练中的 Q(s,a) 使用数据动作；下一状态目标由 V(s′) 给出，不调用新 actor 采样再查询 Q。这避免了一个主要外推通道，但没有证明神经网络在所有未见状态、未见动作上都可靠。

actor 的行为克隆本身会泛化，部署时仍可能输出数据未出现过的动作。IQL 也不能从完全不包含通向目标信息的数据中凭空恢复最优策略。将它称为“保守 Q 惩罚”不准确：其核心是 expectile 备份与策略提取，而非 CQL 那样的显式数据外 Q 惩罚。

## 6. 优缺点与适用边界

![IQL优缺点](/rl-iql-3.png)

价值学习和策略提取分离，便于只学习 critic 后配合其他动作提取方法，QGF 就采用这种组合。限制是数据覆盖、τ 与指数权重敏感性，以及 critic 本身的函数逼近误差。

离线验证不应只报告加权克隆损失。需要独立环境评估，或明确说明离线评估器的假设与不确定性；训练数据里的高 Q 不等于真实高回报。

## 7. 两点 expectile 算例

设固定状态下两个数据动作的 Q 值为 0、2，概率各 1/2。τ=0.75，且 V∈[0,2]，目标为 0.5×0.25V²+0.5×0.75(2−V)²，导数为零得到 V=1.5；普通均值是 1。

于是两个动作优势为 −1.5、0.5，β=1 时权重比为 exp(2)≈7.389。较好动作得到更大权重，但它仍然是数据里的动作。这个例子也说明 expectile 不是“取 75% 排位的那个样本”。
