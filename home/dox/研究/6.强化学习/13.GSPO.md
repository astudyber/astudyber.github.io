# GSPO：让比率、奖励与裁剪对齐到序列

## 1. 时间与方法全称

**组序列策略优化（Group Sequence Policy Optimization，GSPO）**由 Qwen 团队于 **2025 年 7 月 24 日**公开。它保留同题多答的组相对优势，改用长度归一化序列似然比和序列级裁剪。本文讨论基础 GSPO，并单独说明 GSPO-token，二者不可混用梯度实现。

## 2. 核心思想

![GSPO核心思想](/rl-gspo-1.png)

当奖励评价整条回答时，用一条回答的整体概率变化决定其更新权重。多个 token 的 log 比率先平均，再取指数，得到一个序列比率；它是 token 比率的几何平均，不是算术平均。

这有助控制长序列乘积的数值尺度，但也改变了原始重要性采样权重。理论上的完整序列换测度，与为稳定训练设计的归一化代理目标必须区分。

## 3. 原论文比率、目标与符号

原文式 (7) 定义：

$$
s_i(\theta)=\left(\frac{\pi_\theta(y_i\mid x)}{\pi_{\mathrm{old}}(y_i\mid x)}\right)^{1/T_i}
=\exp\left[\frac1{T_i}\sum_{t=1}^{T_i}\left(\log\pi_\theta(y_{i,t}\mid x,y_{i,<t})-\log\pi_{\mathrm{old}}(y_{i,t}\mid x,y_{i,<t})\right)\right].
$$

原文式 (6) 最大化：

$$
\mathcal J_{\mathrm{GSPO}}=\mathbb E_{x,\{y_i\}\sim\pi_{\mathrm{old}}}\left[\frac1G\sum_{i=1}^G\min\left(s_i\hat A_i,\operatorname{clip}(s_i,1-\epsilon,1+\epsilon)\hat A_i\right)\right].
$$

$$
\hat A_i=\frac{r(x,y_i)-\operatorname{mean}_j r(x,y_j)}{\operatorname{std}_j r(x,y_j)}.
$$

| 符号 | 说明 |
| --- | --- |
| x、yi、yi,t | 提示、第 i 条回答、其中第 t 个 token |
| Ti | 回答有效长度，只统计参与目标的响应 token |
| G、r、Âi | 组大小、回答奖励、组内归一化优势 |
| si | 长度归一化序列比率，不是完整原始 IS 权重 |
| πθ、πold | 当前模型、采样旧模型 |
| ε | 序列比率裁剪半宽，不能直接照搬 token 级超参数 |
| sg | stop-gradient，仅在指定的变体或标签中使用 |

原文为突出算法省略 KL 正则，正文公式沿用这一范围；实际训练是否加入参考 KL 应单独说明。标准差为零时也需要显式工程处理，不能产生 NaN。

## 4. 网络流程与正确梯度

![GSPO序列级流程](/rl-gspo-2.png)

骨干仍是自回归语言模型，不需要专门的 GSPO 网络层。旧策略生成回答，验证器评分，当前与旧模型给出 log 概率。对每条回答计算 si，与固定组优势组成目标。

忽略裁剪的激活边界，基础 GSPO 的梯度为：

$$
\nabla_\theta(s_i\hat A_i)=s_i\hat A_i\frac1{T_i}\sum_t\nabla_\theta\log\pi_\theta(y_{i,t}\mid x,y_{i,<t}).
$$

同一回答的 token 共享序列系数，但仍通过各自 log 概率获得梯度。基础 GSPO 中若先把整个 si detach，再直接作为损失，会错误地丢失策略梯度。

## 5. GSPO-token 与重要性采样边界

原文另给出 token 变体，通过特殊 stop-gradient 结构保留序列级前向比率，同时开放 token 级优势：

$$
s_{i,t}(\theta)=\operatorname{sg}[s_i(\theta)]\frac{\pi_\theta(y_{i,t}\mid x,y_{i,<t})}{\operatorname{sg}[\pi_\theta(y_{i,t}\mid x,y_{i,<t})]}.
$$

分母是当前概率的停止梯度副本，不是旧策略概率。这一表达前向值等于 si，反向路径不同；随后还要按 token 平均，不能只复制一半定义。

完整序列比率 W=πθ(y∣x)/πold(y∣x) 满足标准 IS 恒等式，而 s=W^(1/T) 一般不满足同一恒等式。裁剪进一步引入代理目标。原论文对 token 级比率的稳定性分析是算法动机，不能概括为“所有 token 级策略梯度在数学上都无效”。

## 6. 优缺点与边界

![GSPO优缺点](/rl-gspo-3.png)

序列级单位与结果奖励相配，长度归一化缓和乘积爆炸，论文在其大型模型训练中报告了稳定性收益。但组内零方差、奖励漏洞、长度分布变化和离策略漂移仍然存在；它不保证所有任务都优于 GRPO。

裁剪也不是不分优势符号地丢弃所有超区间序列：与 PPO 一样，只有沿有利方向越界的单项被截平。实测 clip fraction 必须说明统计定义。

## 7. 算例与检查

两个 token 的新旧比率为 4 和 1/4，则原始序列比率为 1，GSPO 比率为 √1=1，算术平均却为 2.125。若两个比率均为 4，则 W=16、s=4，说明长度次根确实改变了权重。

检查 response mask、EOS、padding 与长度分母是否一致；空回答应预先处理，不能令 T=0。用自动微分核对上面的基础梯度，再单独实现 GSPO-token，避免 stop-gradient 放错位置。
