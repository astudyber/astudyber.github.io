# Physical Intelligence π系列（π₀ / π₀-FAST / π₀.5 / π₀.6 / π₀.7）完整整理

> π系列全称Vision-Language-Action(VLA)机器人基础模型，由Physical Intelligence团队提出，主线：**VLM骨干 + Action Expert**；π₀是流匹配连续动作路线，π₀-FAST是同骨干、换成D(\mathcal C)T频域动作token自回归路线，后续π0.5/0.6/0.7在这个底座上持续升级泛化、学习范式、记忆与组合能力

## π₀（2024.10，开山之作）

### 基本框架

整体：**PaliGemma 3B VLM骨干（SigLIP视觉编码器 + Gemma语言模型） + 300M Flow Matching Action Expert**，Decoder-only双分支Transformer。

1. 前缀token：多视角图像token + 自然语言指令token（VLM分支处理感知、语义理解）
2. 后缀token：机器人本体状态proprioception + 带噪动作块（Action Expert分支）
3. 推理：ODE求解器迭代去噪，一次性生成未来H步**50Hz连续动作轨迹**，输出关节/末端执行器连续控制量，跨7种机器人本体、68项任务，单权重通用策略

### 解决的核心问题

1. 传统机器人策略只能单本体、单任务，难以泛化；
2. 扩散模型做连续动作训练不稳定、推理步数多；
3. VLM语义知识无法直接映射到高频连续电机控制；
4. 缺少统一VLA底座，同时支持语言指令、视觉观察、连续机器人动作生成。

### 核心公式（(\mathcal C)onditional Flow Matching，(\mathcal C)FM）

动作插值： $$A^\tau = \tau A_1 + (1-\tau)\epsilon$$ $\tau\in[0,1]$；$A_1$是真实动作轨迹，$\epsilon$是高斯噪声；$A^\tau$是插值中间带噪动作块。

训练损失（速度场匹配）： $$\mathcal{L}(\theta)=\mathbb{E}*{o,\tau,A_1,\epsilon}\Big[\big|v*\theta(A^\tau,o,\tau)-(A_1-\epsilon)\big|*2^2\Big]$$ $o$ = 观测（图像+语言+本体状态）；$v*\theta$是模型预测速度场；目标是拟合真实流场$u^*=A_1-\epsilon$。 推理：ODE $\frac{dA}{d\tau}=v_\theta(A,o,\tau)$，从$\tau=0$（纯噪声）积分到$\tau=1$得到完整动作序列。

## π₀-FAST（2025.01，π₀的并行高效分支，也叫π0-Faster）

### 基本框架

**骨干和π₀完全一致（PaliGemma 3B），但Action Expert从Flow Matching连续生成改为自回归离散token预测**。 核心模块：**FAST Action Tokenizer**

1. 将连续动作chunk做D(\mathcal C)T离散余弦变换，保留重要频域系数，丢弃高频冗余分量；
2. 对D(\mathcal C)T系数做BPE字节对编码，压缩成短离散动作token序列；
3. Transformer自回归next-token预测；推理时FAST解码器把token还原回连续动作轨迹。

### 解决的核心问题

1. π₀流匹配需要ODE迭代，推理开销大、显存高，LoRA微调困难；

2. 传统逐维分桶离散动作token：token序列极长、时序高度冗余，模型只会复制前一token，学不到真实运动结构；

3. 训练慢，无法大规模快速迭代VLA。

   > 效果：同等数据下**训练速度提升5倍**，推理更快，支持LoRA微调；代价：动作精度略低于原生π₀流匹配版本

### 核心公式

D(\mathcal C)T对单维度动作序列$\boldsymbol a\in\mathbb R^H$： $$(\mathcal C)*k=\sum*{t=0}^{H-1}a_t\cos\left[\frac{\pi}{H}(t+\tfrac12)k\right],\quad k=0\dots H-1$$ 截断：保留前$K$个低频D(\mathcal C)T系数，丢弃高频；将系数量化+BPE得到离散动作token。 训练目标：标准自回归交叉熵 $$\mathcal L=-\sum_i \log p_\theta(\text{token}*i | \text{token}*{<i},\text{image,text})$$

## π₀.5（2025.04，开放世界泛化版本）

### 基本框架

沿用VLM+Action Expert架构，骨干仍为3B PaliGemma；两大新增机制：

1. **异构共训练（Heterogeneous (\mathcal C)o-training）**：混合4类数据：网页图文、多家庭环境、跨本体机器人示范、高层子任务标注；不再只在机器人演示数据上训练。
2. 分层条件VLA：VLM输出高层子任务规划，Action Expert接收**子任务条件**，生成底层连续动作；引入AdaRMS条件调制，本体状态不再作为独立后缀token，嵌入到条件信号中。
3. 知识隔离（Knowledge Insulation）：VLM语义骨干梯度与Action Expert控制梯度做边界隔离，防止控制任务的梯度破坏预训练语言/视觉知识

### 解决的核心问题

π₀只能在训练见过的环境里工作；π0.5目标：**零泛化到从未见过的家庭、未知物体、全新环境，支持长时序多阶段家务任务**（叠衣服、收拾房间）。

### 核心公式

知识隔离损失： $$\mathcal L_{total}=\mathcal L_{VLM_semantic}+\lambda\cdot\mathcal L_{action}$$ 通过梯度掩码，$\mathcal L_{action}$的梯度**不更新VLM骨干语义参数**，只更新Action Expert；仅$\mathcal L_{VLM_semantic}$更新VLM，保护预训练视觉语言能力。 AdaRMS条件归一化： $$h'=\text{AdaRMS}(h, c),\quad c=\text{MLP}(\tau,\text{subtask embedding})$$ $c$为子任务+时间条件，调制Transformer归一化层，实现分层控制。

## π₀.6（π*0.6，2025.11，从真实交互经验学习）

### 基本框架

- 骨干升级：VLM扩容至5B（Gemma3 4B），Action Expert从300M提升至860M；图像分辨率224→448，支持最多四路相机输入。

- 新增**RE(\mathcal C)AP强化学习框架**：Offline预训练 + 机器人自主部署收集在线数据 + 人工干预校正数据混合训练；

- 配套MEM多尺度具身记忆模块：短期视频时序记忆 + 长期文本任务记忆，维护长任务上下文。

  > π0.6基础版是纯监督；π*0.6=π0.6 + RE(\mathcal C)AP在线经验强化学习（星号代表经过交互自改进）

### 解决的核心问题

前面版本全部是**离线示范学习，只能从人类成功轨迹学习，无法从失败、自主试错中学习**； RE(\mathcal C)AP让模型从机器人自主执行失败样本、人工纠错信号里迭代，提升真实环境任务吞吐率、降低失败率，例如做意式咖啡任务成功率>90%。

### RE(\mathcal C)AP核心公式（优势条件策略）

$$\mathcal L_{\text{RE(\mathcal C)AP}}=\mathbb E\left[\log \pi(a|o,c)\cdot (A(o,a))\right]$$ $(A(o,a))$是优势函数，由轨迹回报、人工干预修正信号共同估计；策略不仅学习示范，还学习区分好坏行为，对高优势动作加权。

## π₀.7（2026.04，可操控通用机器人基础模型，涌现组合泛化）

### 基本框架

VLM+Action Expert底座继续升级；核心创新：**Steerable可控策略 + 组合技能泛化**

1. 混合质量数据训练：同时使用高质量专家轨迹、低质量自主试错轨迹；
2. 统一多粒度指令接口：高层自由文本、子任务指令、低层动作条件都可以作为控制信号；
3. 原生跨本体组合泛化：能重组已学到的基础技能，解决**训练完全没见过的新任务/新工具**，不需要任务专属微调。
4. 更强的多视图时序上下文，长任务记忆优化。

### 解决的核心问题

过往VLA只能插值已见过任务，缺少**技能组合能力**；比如见过“抓取杯子”和“操作咖啡机”，但无法组合成操作全新型号咖啡机；π0.7出现类似大语言模型的**组合泛化（compositional generalization）**，开箱即达到专家微调模型的灵巧操作水平。

### 核心思想公式（条件策略）

$$\pi(a_{1:H}|o_{1:T},\mathcal (\mathcal C))=\pi_{\text{action}}(a_{1:H}\mid \text{VLMEncoder}(o_{1:T},\mathcal (\mathcal C)))$$ $\mathcal (\mathcal C)$可以是自然语言指令、子任务、技能描述、修正反馈；模型将不同粒度的控制信号统一编码为条件，生成动作序列； 训练目标混合监督流匹配损失 + 基于反馈的策略加权损失。
