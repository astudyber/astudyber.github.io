# 1. 注意力的直觉

## 1.1 查询、记忆与加权读取

注意力把“查找相关信息”写成可微运算：查询 Q 与键 K 计算相关性，归一化得到权重，再对值 V 加权求和。键负责匹配，值负责被读取的内容，二者可以来自同一输入但使用不同投影。

![查询、匹配与加权读取](/attention-qkv.png)

图中一次查询可以从多个记忆条目取信息，不必只选一个。权重高表示该计算对某个位置分配更多读取比例，不自动构成可靠的人类因果解释；值向量和后续层也会影响输出。

# 2. 核回归

## 2.1 Nadaraya–Watson 与可学习权重

Nadaraya–Watson 核回归用距离核加权邻近样本：$\hat y(x)=\sum_i\alpha_i(x)y_i$，其中权重非负且和为 1。核带宽小，估计更局部；带宽大，结果更平滑。

将距离和表示变成可学习对象，就接近注意力的思想。注意力不仅能在原始输入坐标中找邻居，也能在任务学习出的空间中匹配；但相似度结构仍需由数据和训练目标塑造。

# 3. 缩放点积注意力与加性注意力

## 3.1 评分、缩放与 softmax

缩放点积注意力为 $\operatorname{softmax}(QK^\top/\sqrt{d_k})V$。除以 $\sqrt{d_k}$ 用于控制高维点积的尺度，缓解 softmax 过早饱和；其直觉通常基于分量尺度相近的假设。

加性注意力先对查询与键做可学习变换，再通过非线性产生标量分数。两者的表达形式、计算友好程度不同，不能仅凭公式长度判断优劣。Q 与 K 的特征维匹配，V 的特征维可以不同。

## 3.2 掩码、数值稳定性与复杂度

掩码在 softmax 前把禁止访问位置设为极小分数，使其权重为零。padding mask 排除无效 token，causal mask 排除未来 token，二者可以同时存在。

![下三角可见区域与未来屏蔽区域](/attention-mask.png)

图中第 t 行最多访问前 t 个位置。若某行全部被屏蔽，朴素 softmax 可能产生未定义结果，需要约定输出处理。标准密集注意力计算量随长度近似二次增长，显式分数矩阵也占用二次存储。

# 4. 多头注意力

## 4.1 子空间、拼接与输出投影

多头注意力使用多组投影在不同子空间中并行读取，拼接各头结果后再做输出投影。头之间并不天然对应固定的语法或视觉概念，功能会随训练形成。

当总模型维度固定时，增加头数通常减小每头维度；它不是无成本增加容量。实现时应检查 reshape 与转置轴，避免把 token 轴当成 head 轴。

## 4.2 MQA、GQA 与 MLA

MHA 为每个查询头保留独立 KV 头；MQA 让所有查询头共享一组 KV；GQA 在两者之间按组共享。共享减少缓存量，但模型需要适配这种结构。

![MHA、GQA 与 MQA 的共享关系](/attention-heads.png)

图中查询头数相同，KV 组数逐渐减少。MLA 进一步压缩 KV 表示，其实现还涉及位置编码与恢复计算；不能把它简单视为“更少的普通 KV 头”。参见 [GQA 论文](https://arxiv.org/abs/2305.13245) 与 [DeepSeek-V3](https://arxiv.org/abs/2412.19437)。

# 5. 自注意力与交叉注意力

## 5.1 Q、K、V 的来源

自注意力的 Q、K、V 来自同一序列，允许序列内部交换信息；交叉注意力的 Q 来自目标侧，K、V 来自另一来源，例如文本解码器读取图像编码器的特征。

判断类型看来源，不看模块名字。跨注意力的分数矩阵为目标长度乘源长度，因此源分辨率或检索条目数也会影响成本。

## 5.2 因果掩码与编码器—解码器

编码器通常允许双向读取输入，因果解码器只能读取前缀。编码器—解码器模型的目标侧同时有因果自注意力与读取源表示的交叉注意力。

训练时可以并行计算目标序列各位置，但必须施加因果掩码，确保每个位置只能使用允许的信息。并行训练与自回归生成并不矛盾：前者已知所有标签，后者必须逐步产生未知 token。

# 6. 位置编码

## 6.1 正弦位置编码与相对位置

没有位置机制的自注意力对输入排列具有相应的置换性质，难以独自区分顺序。正弦编码使用不同频率表达位置，学习式位置嵌入则直接学习位置向量。

相对位置方法关注 token 间距离。位置编码加入方式会影响长序列推广；训练中没见过的位置或距离不一定可靠，形式上能计算并不等于语义上能泛化。

## 6.2 RoPE 与长上下文限制

RoPE 对查询和键做与位置相关的旋转，使它们的点积包含相对位置关系。它不通过简单增加一个位置向量工作，也不意味着可以无限延长上下文而不损失质量。

长上下文扩展可能调整频率或缩放，并辅以继续训练。评估应覆盖远距离检索、跨段推理和位置偏置，而不只验证模型能接受某个长度的输入。[RoFormer 论文](https://arxiv.org/abs/2104.09864)。

# 7. Transformer

## 7.1 编码器、解码器与残差归一化

Transformer 块通常包含跨位置的注意力与逐位置的前馈网络，再配残差和归一化。Pre-Norm 把归一化放在子层之前，Post-Norm 放在残差相加之后，优化行为会不同。

![Pre-Norm Transformer 块](/attention-transformer.png)

图中两条短路径分别绕过注意力和 FFN；归一化不是替代残差。前馈网络在不同位置共享参数，但不直接交换位置间信息，跨位置交互主要由注意力完成。

## 7.2 训练、生成与 KV cache

自回归生成时，旧 token 的 K、V 可以缓存，新 token 的 Q 读取已有缓存。这样避免每步重算整个前缀，但缓存仍随长度增长。

![增量缓存与分块精确注意力](/attention-cache.png)

图左是跨生成步骤复用状态，图右是单次注意力内部减少读写，它们优化的层面不同。缓存应与模型、位置、掩码和前缀严格对应；错误复用会得到看似合理但不正确的输出。

# 8. 现代高效注意力

## 8.1 FlashAttention 与 IO 复杂度

FlashAttention 通过分块与在线 softmax，避免将完整注意力矩阵反复写入高带宽显存，在数学上仍计算密集注意力；浮点累加顺序可能带来微小差异。[原论文](https://arxiv.org/abs/2205.14135)。

2026 年 FlashAttention-4 针对硬件计算与带宽增长不均衡，进一步设计流水线和内核。它的收益与 GPU、精度、头维和序列长度有关，不能把特定配置的加速倍率推广到所有场景。[FA4 论文](https://arxiv.org/abs/2603.05451)。

## 8.2 线性注意力、混合架构与评测

线性注意力通常改变相似度形式或重排计算，利用可累积状态降低某些长度相关成本；这与仅改变计算顺序的精确 FlashAttention 不同。混合模型可以交替使用注意力与状态空间等模块。

比较时同时报告质量、长程检索、训练吞吐、decode 延迟与缓存大小。只给渐近复杂度会忽略常数项、并行性和硬件利用率；只给一个短长度速度也不能说明长上下文表现。

## 综合算例：一次加权读取

假设某查询对两个键的分数为 (0,ln3)，softmax 权重就是 (1/4,3/4)。若两个值向量分别为 (2,0) 和 (0,4)，输出为 (0.5,3)。键影响权重，值决定被混合的内容；二者承担不同角色。

若第二个位置被掩码屏蔽，权重变成 (1,0)，输出为 (2,0)。先加权再“删除未来输出”不能替代在 softmax 前施加掩码，因为归一化分母已经被未来位置影响。

## 复杂度与缓存算例

长度 4096、16 个头的完整分数矩阵含 $16\times4096^2$ 个元素，仅用 2 字节存储就约为 512 MiB，尚未计梯度与其他激活。FlashAttention 主要避免这类完整中间矩阵的显存存储，并不将密集注意力的全部乘加变成线性复杂度。
