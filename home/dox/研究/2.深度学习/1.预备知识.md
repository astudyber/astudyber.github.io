# 1. PyTorch 入门

## 1.1 张量、形状与数据类型

张量把数值、形状、类型与设备放在同一个对象中。一个 RGB 图像批次通常写作 $X\in\mathbb{R}^{B\times3\times H\times W}$；B 是样本数，不能与通道数混用。浮点张量用于可微计算，类别索引通常是整数，掩码通常是布尔值。

![标量、向量、矩阵与批量张量](/basics-tensors.png)

读图时逐个追踪轴：把一张图扩展为一个批次，只增加样本轴，并没有新增颜色通道。排错顺序是 shape → dtype → device → 数值范围；只看总元素数相同，无法证明语义相同。

## 1.2 索引、广播与内存视图

广播从末尾维度开始对齐，每一对维度必须相等，或至少一个为 1。因此 [2,3]+[3] 合法，[2,3]+[2] 通常不合法。广播一般不真实复制所有数据，但后续运算仍可能产生大结果。

![广播的尾轴对齐规则](/basics-broadcast.png)

图中的一行特征被应用到两个样本；它不是把两个样本求和。切片常返回共享存储的视图，修改视图可能改变原张量；高级索引通常产生新张量。转置后布局可能不连续，reshape 能否共享存储取决于步幅，不能把它与复制画等号。

## 1.3 从数据到一次参数更新

一次训练迭代包含：取数据、前向、算损失、清空旧梯度、反向、更新参数。设 $L(\theta)$ 为批量平均损失，最基本的更新是 $\theta\leftarrow\theta-\eta\nabla_\theta L$。反向传播只计算梯度，优化器才改变参数。

先用少量样本做一次完整闭环：预测形状与目标一致，loss 为有限标量，至少一个参数有非零梯度，更新后参数发生变化。若这四点未满足，扩大模型只会扩大问题。

## 1.4 创建、类型与设备：先把契约写清楚

```python
import numpy as np
import torch
from torch import nn

torch.manual_seed(7)
x = torch.arange(6, dtype=torch.float32).reshape(2, 3)
y = torch.tensor([0, 1], dtype=torch.long)
mask = x > 2
z = torch.zeros_like(x)
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
x = x.to(device=device, dtype=torch.float32)
```

`shape` 是各轴长度，`ndim` 是轴数，`numel()` 是元素总数。`dtype` 影响精度与算子语义，`device` 决定计算位置；参与同一次运算的张量通常需要在同一设备。`.to(...)` 返回转换结果，应接住返回值；类型、设备都相同时不保证产生副本。

| 意图 | 关键语法 | 容易混淆之处 |
| --- | --- | --- |
| 从数据创建独立张量 | `torch.tensor(data)` | 复制数据；不是保留已有张量计算图的办法 |
| 尽量复用已有存储 | `torch.as_tensor(data)` | 是否共享取决于输入、类型和设备 |
| 与 NumPy 共享 CPU 存储 | `torch.from_numpy(a)` | 支持的数组类型才能转换；修改会相互影响 |
| 等间隔整数 / 固定数量采样 | `torch.arange(0, 6, 2)` / `torch.linspace(0, 1, 5)` | 前者右端不包含，后者默认包含两端 |
| 正态 / 均匀随机数 | `torch.randn(2, 3)` / `torch.rand(2, 3)` | 分别是标准正态与 [0,1) 均匀分布 |
| 转浮点 / 转类别索引 | `x.float()` / `y.long()` | 交叉熵的类别索引目标通常用 long |
| 取单个 Python 数 | `loss.item()` | 仅适合单元素张量；GPU 上可能触发同步 |
| 导出 NumPy 快照 | `x.detach().cpu().numpy().copy()` | `.numpy()` 本身可能共享 CPU 存储 |

## 1.5 形状语法：改变分组与交换轴不是一回事

![PyTorch 形状操作对照](/syntax-torch-shape.png)

图中要区分“数据仍按原顺序重新分组”和“轴的含义互换”。将图像从 HWC 转为 CHW 应交换轴，不能仅 reshape 成相同目标形状。

```python
x = torch.arange(6).reshape(2, 3)
a = x.reshape(3, 2)           # [[0, 1], [2, 3], [4, 5]]
b = x.transpose(0, 1)         # [[0, 3], [1, 4], [2, 5]]
assert not torch.equal(a, b)
batch = torch.stack([x, x], dim=0)  # [2, 2, 3]，新增轴
joined = torch.cat([x, x], dim=0)   # [4, 3]，沿已有轴拼接
row = x[0:1, :]               # [1, 3]，保留轴
vector = x[0, :]              # [3]，整数索引消去轴
```

| 操作 | 示例及结果 | 判断依据 |
| --- | --- | --- |
| 重排元素分组 | `x.reshape(3, 2)` | 元素数不变；可能返回视图，也可能复制 |
| 仅允许兼容步幅的视图 | `x.view(3, 2)` | 不满足布局条件时会报错 |
| 交换两轴 / 任意轴排列 | `x.transpose(0, 1)` / `t.permute(0, 3, 1, 2)` | 通常改变 stride，可能不连续 |
| 增加 / 删除长度为 1 的轴 | `x.unsqueeze(0)` / `t.squeeze(1)` | 显式指定轴可避免 batch=1 时误删批量轴 |
| 展平后续维度 | `t.flatten(start_dim=1)` | 保留第 0 维作为样本轴 |
| 沿轴归约 | `x.float().mean(dim=0, keepdim=True)` | 结果 [1,3]，可继续广播 |
| 广播扩展 / 实际重复 | `row.expand(4, -1)` / `row.repeat(4, 1)` | expand 使用共享视图，不应逐元素原地写入 |
| 连续存储 | `t.contiguous()` | 已连续时可能直接返回原张量 |

## 1.6 复制、共享与梯度关系

![存储关系与计算图关系分开判断](/syntax-torch-storage.png)

存储是否共享、梯度是否连通是两个独立问题。`clone()` 复制存储但保留可微关系；`detach()` 切断梯度但共享存储；`detach().clone()` 才同时得到独立且不连图的快照。

```python
a = np.array([1., 2.], dtype=np.float32)
t = torch.from_numpy(a)
t[0] = 9
assert a[0] == 9
u = torch.tensor([1., 2.], requires_grad=True)
v = u.clone()
v.sum().backward()
assert torch.equal(u.grad, torch.ones_like(u))
snapshot = u.detach().clone()
snapshot[0] = -1
assert u[0].item() == 1
```

高级索引读取通常返回副本，但 `x[mask] = value` 是对原对象赋值。不要因为“读取返回副本”而推断赋值不会修改原对象。对梯度所需中间值原地修改还可能破坏反向传播。

## 1.7 模型、损失与完整训练语法

![训练步骤与推理状态对照](/syntax-torch-train.png)

图中 `backward()` 负责求导，`step()` 负责更新。`model.eval()` 控制层的行为，`no_grad()` 控制是否记录计算图；正常推理一般同时使用两者。

```python
import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader

torch.manual_seed(7)
features = torch.randn(64, 3)
targets = (features[:, 0] > 0).long()
loader = DataLoader(TensorDataset(features, targets), batch_size=16, shuffle=True)
model = nn.Sequential(nn.Linear(3, 8), nn.ReLU(), nn.Linear(8, 2))
optimizer = torch.optim.AdamW(model.parameters(), lr=0.01, weight_decay=0.01)
criterion = nn.CrossEntropyLoss()
model.train()
for xb, yb in loader:
    optimizer.zero_grad(set_to_none=True)
    logits = model(xb)
    loss = criterion(logits, yb)
    loss.backward()
    optimizer.step()
model.eval()
with torch.no_grad():
    probabilities = model(features).softmax(dim=-1)
    predictions = probabilities.argmax(dim=-1)
assert probabilities.shape == (64, 2)
```

| 任务 | 模型输出与目标 | 损失入口 |
| --- | --- | --- |
| 单标签多分类 | logits [B,C]；类别索引 [B] | `nn.CrossEntropyLoss()`，不要预先 softmax |
| 二分类 / 多标签 | logits 与浮点目标同形状 | `nn.BCEWithLogitsLoss()`，不要预先 sigmoid |
| 回归 | 预测与目标形状严格一致 | `nn.MSELoss()`；防止 [B,1] 与 [B] 意外广播 |
| 自定义模块 | 继承 `nn.Module`，定义 `forward` | 用 `model(x)` 调用以保留 hooks 等模块机制 |
| 只冻结参数 | `p.requires_grad_(False)` | 不自动切换 eval，也不必然阻断输入梯度 |
| 保存 / 恢复 | `torch.save(model.state_dict(), path)` | 先重建相同结构，再 `load_state_dict` |

学习率调度器按其设计的频率调用；梯度累积时不能每个微批次都清空梯度。恢复训练还需要优化器、调度器、训练步数及必要的随机状态，只有权重不足以恢复完整训练过程。


# 2. pandas 入门

## 2.1 表格读取与缺失值

表格读取后先检查列类型、缺失比例、重复行和异常单位。缺失值可能代表“未采集”“不适用”或真实的零，不能一律填零。数值列可用训练集的中位数填充；缺失本身有信息时增加指示列。

把预处理也视为模型的一部分：记录列顺序、填充值、尺度和类别字典，推理阶段复用这些状态。日期、用户标识、事后统计量最容易携带隐蔽的目标信息。

## 2.2 分类特征、划分与数据泄漏

无序类别可独热编码；高基数类别可学习嵌入；自然有序类别才适合直接映射为有序整数。给“红、绿、蓝”编码 0、1、2 并交给线性模型，会凭空加入距离关系。

应先按实体或时间划分，再拟合填充、标准化、特征选择等操作。同一个人的多条记录跨越训练与测试，即使行号不同，也可能构成泄漏。测试集只承担最终评估，不用于挑选预处理策略。

## 2.3 选择与赋值：标签和位置分开想

![pandas 的 loc 与 iloc 语法](/syntax-pandas-index.png)

`loc` 按标签，`iloc` 按整数位置。标签切片通常包含终点，位置切片不包含终点。单列 `df['score']` 是 Series，列名列表 `df[['score']]` 是二维 DataFrame；保留二维结构常能减少后续形状分支。

```python
import pandas as pd

df = pd.DataFrame({'group': ['A', 'A', 'B'], 'score': [10., None, 30.]},
                  index=['u1', 'u2', 'u3'])
first_two = df.loc['u1':'u2', ['score']]  # 包含 u2
same_rows = df.iloc[0:2, [1]]           # 不包含位置 2
missing = df['score'].isna()
df.loc[missing, 'score'] = 20.           # 一次索引完成赋值
assert df.loc['u2', 'score'] == 20.
```

| 意图 | 写法 | 语义 |
| --- | --- | --- |
| 查看模式 | `df.head()`、`df.info()`、`df.dtypes` | 先检查类型与缺失，再算统计量 |
| 筛选行 | `df.loc[df['score'] >= 20]` | 条件按行产生布尔掩码 |
| 多条件 | `df.loc[(df['score'] >= 20) & (df['group'] == 'A')]` | 每个比较加括号；不用 Python 的 and |
| 指定行列赋值 | `df.loc[mask, 'score'] = 0` | 避免 `df[mask]['score'] = 0` 链式赋值 |
| 新列 | `df.assign(double=df['score'] * 2)` | 返回新对象；不自动写回 df |
| 排序 | `df.sort_values('score', ascending=False)` | 返回新对象；索引标签默认保留 |
| 重设索引 | `df.reset_index(drop=True)` | 丢弃旧标签并生成位置式索引 |
| 删除重复实体 | `df.drop_duplicates(subset=['user_id'])` | 先定义实体与保留规则，不能盲目去重 |

Series 运算和赋列会按索引标签对齐，不是单纯按当前位置。若确实要按位置赋值，先核对顺序，再显式转换为数组。pandas 3.0 起 Copy-on-Write 是默认且唯一模式，派生对象的写入不用于隐式修改父对象；代码应采用上面的单步 `.loc` 赋值。详见 [官方 Copy-on-Write 说明](https://pandas.pydata.org/docs/user_guide/copy_on_write.html)。

## 2.4 缺失、类型与类别的关键语法

```python
raw = pd.DataFrame({'age': ['20', '?', '40'], 'city': ['A', 'B', 'A']})
raw['age'] = pd.to_numeric(raw['age'], errors='coerce')
train = raw.iloc[:2].copy()
valid = raw.iloc[2:].copy()
fill_value = train['age'].median()
train['age_missing'] = train['age'].isna().astype('int8')
valid['age_missing'] = valid['age'].isna().astype('int8')
train['age'] = train['age'].fillna(fill_value)
valid['age'] = valid['age'].fillna(fill_value)
train_x = pd.get_dummies(train, columns=['city'], dtype=float)
valid_x = pd.get_dummies(valid, columns=['city'], dtype=float)
valid_x = valid_x.reindex(columns=train_x.columns, fill_value=0)
assert train_x.columns.equals(valid_x.columns)
```

这个小例子强调训练集拟合、验证集复用；实际任务应先按实体或时间合理划分。`errors='coerce'` 会把无法解析的值变成缺失，须统计转换失败数量。全缺失的训练列无法得到有效中位数，需要明确删除或使用领域常量。

| 操作 | 常用写法 | 注意 |
| --- | --- | --- |
| 读取 / 保存 | `pd.read_csv(path)` / `df.to_csv(path, index=False)` | 指定编码、类型和日期规则；文件路径是运行环境路径 |
| 缺失检测 | `s.isna()` / `s.notna()` | 不用 `s == np.nan` 判断缺失 |
| 可空整数 | `s.astype('Int64')` | 大写 I 的可空类型与普通 int64 不同 |
| 日期解析 | `pd.to_datetime(s, errors='coerce', utc=True)` | 时区与本地时间解释必须明确 |
| 字符串批量处理 | `s.astype('string').str.strip().str.lower()` | 保留缺失语义，避免先转成字面字符串 nan |
| 类别编码 | `pd.get_dummies(df, columns=['city'])` | 未知类别策略要显式设计；全零不总是合理 |
| 转数值矩阵 | `df.to_numpy(dtype='float32', copy=True)` | 标签信息丢失；混合类型先处理 |

## 2.5 分组、连接与长宽表

![聚合、广播回原行和连接的区别](/syntax-pandas-join.png)

读图时观察输出行数：`agg` 通常每组一行，`transform` 保持原行数并与原索引对齐，`merge` 的行数则由键的匹配关系决定。连接前后都检查样本数，能够发现重复键导致的意外膨胀。

```python
orders = pd.DataFrame({'user': ['a', 'a', 'b'], 'amount': [10., 30., 8.]})
summary = orders.groupby('user', as_index=False).agg(total=('amount', 'sum'))
orders['group_mean'] = orders.groupby('user')['amount'].transform('mean')
users = pd.DataFrame({'user': ['a', 'b'], 'region': ['N', 'S']})
joined = orders.merge(users, on='user', how='left', validate='many_to_one')
assert len(joined) == len(orders)
assert orders['group_mean'].tolist() == [20., 20., 8.]
```

`pd.concat([a,b], ignore_index=True)` 主要按轴拼接，`merge(..., on=...)` 按键关联。`pivot` 要求每个行列键对应唯一值；有重复观测时使用 `pivot_table(..., aggfunc=...)` 并说明聚合方式；`melt` 将宽表变为长表。组内均值若包含未来记录或验证集，也会泄漏，语法正确并不保证实验正确。


# 3. NumPy 入门

## 3.1 向量化、轴与广播

向量化把 Python 层的逐元素循环交给底层数组算子。对 $X\in\mathbb R^{B\times d}$ 沿 axis=0 求均值，得到每个特征的统计量；沿 axis=1 求均值，得到每个样本的统计量。保留被约简的维度有助于后续广播。

例如标准化 $Z=(X-\mu)/(\sigma+\epsilon)$ 中，$\mu,\sigma$ 应为 [1,d] 的训练集统计量。向量化不意味着无限制构造中间矩阵：两两距离的朴素广播可能临时占用 $O(B^2d)$ 内存。

## 3.2 NumPy 与张量的共享和复制

CPU 上某些 NumPy 数组与张量转换可以共享内存；GPU 张量转为 NumPy 则需要先传回 CPU。共享适合减少复制，但一侧原地写入会影响另一侧。

对带梯度的张量，导出观察值时先脱离计算图，再搬到 CPU。detach 只改变自动微分关系，并不保证复制存储；需要独立快照时还应 clone。性能分析要把数据搬运时间单独计入。

## 3.3 创建、索引与归约速查

![NumPy 的 axis 与 keepdims](/syntax-numpy-axis.png)

把 axis 理解为“本次被消去的轴”：二维样本矩阵沿 axis=0 归约样本，留下特征；沿 axis=1 归约特征，留下样本。图中 [2,3] 的数组可以直接用下面代码验证。

```python
import numpy as np

x = np.arange(6, dtype=np.float64).reshape(2, 3)
assert np.array_equal(x.sum(axis=0), [3, 5, 7])
assert np.array_equal(x.sum(axis=1), [3, 12])
mean = x.mean(axis=0, keepdims=True)
centered = x - mean
assert mean.shape == (1, 3)
assert np.allclose(centered.mean(axis=0), 0)
```

| 目的 | 语法 | 对比 |
| --- | --- | --- |
| 创建数组 | `np.array(data, dtype=np.float32)` | 不同于列表；固定类型便于向量运算 |
| 尽量复用数组 | `np.asarray(data)` | 类型兼容时可复用；不承诺独立副本 |
| 构造数列 | `np.arange(6)` / `np.linspace(0, 1, 5)` | 浮点步长计数宜用 linspace 明确数量 |
| 随机生成 | `rng = np.random.default_rng(7)` | 独立生成器；`rng.normal(size=(2,3))` |
| 条件选值 | `np.where(x > 2, x, 0)` | 三参数形式按位置二选一 |
| 裁剪范围 | `np.clip(x, 0, 3)` | 与删除越界样本不同 |
| 逐元素 / 矩阵乘法 | `x * x` / `x @ x.T` | 前者 [2,3]，后者 [2,2] |
| 排序值 / 排序索引 | `np.sort(x)` / `np.argsort(x)` | 默认沿最后一轴，不是整矩阵统一排序 |
| 拼接 / 新增轴 | `np.concatenate([x,x], axis=0)` / `np.stack([x,x])` | 分别得到 [4,3] 与 [2,2,3] |
| 方差与标准差 | `x.var(axis=0, ddof=1)` / `x.std(axis=0)` | ddof 改变分母；跨库比较先统一约定 |
| 比较浮点结果 | `np.allclose(a, b, rtol=..., atol=...)` | 容差根据尺度选择，不用逐位相等代替误差分析 |

## 3.4 视图、副本与可控内存

![NumPy 切片视图与高级索引副本](/syntax-numpy-copy.png)

```python
x = np.arange(6)
view = x[1:4]
copy = x[[1, 2, 3]]
view[0] = 99
copy[1] = -1
assert x[1] == 99 and x[2] == 2
assert np.shares_memory(x, view)
assert not np.shares_memory(x, copy)
independent = x.copy()
```

基本切片通常是视图；整数数组和布尔数组的高级索引读取产生副本。`reshape`、`ravel` 可能共享也可能复制，`flatten` 返回副本。转置只重新解释轴与步幅的情况很常见，不等于把数据物理搬成新顺序。

[NumPy 2.x](https://numpy.org/doc/stable/numpy_2_0_migration_guide.html) 对 `np.array(..., copy=False)` 的“不许复制”约束比旧版本更严格；如果目标是“能不复制就不复制”，优先 `np.asarray(...)`。多维矩阵乘法用 `@`/`matmul` 时，最后两轴是矩阵轴，前面的轴按广播匹配；不要把高维 `dot` 默认当作同义词。

# 4. Hugging Face Transformers 入门

## 4.1 模型、分词器与任务头

Transformers 把模型配置、预处理、权重加载和任务接口组织在一起。`AutoTokenizer` 根据检查点选择分词器；`AutoModel` 返回基础表征；`AutoModelForCausalLM`、`AutoModelForSequenceClassification` 等加载相应任务头。任务接口必须与检查点架构相容，不能只根据名字随意替换。

![从检查点到生成文本的最短路径](/syntax-hf-workflow.png)

图中的检查点标识要同时用于模型和分词器。`input_ids` 是词表索引，不是词向量；模型内部的 embedding 才把索引映射为连续表征。多模态模型常用 `AutoProcessor` 统一图像、视频与文本预处理，具体返回字段仍以模型文档为准。

| 入口 | 最小语法 | 用途 |
| --- | --- | --- |
| 高层任务流水线 | `pipeline('sentiment-analysis', model=...)` | 快速验证任务输出；显式指定检查点以利复现 |
| 文本编码 | `AutoTokenizer.from_pretrained(model_id)` | 分词、填充、截断、聊天模板 |
| 基础表征 | `AutoModel.from_pretrained(model_id)` | 常见输出含 last_hidden_state；具体字段依模型而定 |
| 自回归生成 | `AutoModelForCausalLM.from_pretrained(model_id)` | 输出词表 logits，并支持 generate |
| 分类任务 | `AutoModelForSequenceClassification.from_pretrained(...)` | 配置类别数；新任务头可能需要训练 |
| 多模态预处理 | `AutoProcessor.from_pretrained(model_id)` | 协调文本和视觉输入，不只是 tokenizer |
| 固定版本 | `from_pretrained(model_id, revision=commit_id)` | 用具体提交固定远程资产，而非浮动分支 |
| 离线载入 | `from_pretrained(local_dir, local_files_only=True)` | 本地目录必须包含完整配置、权重和预处理文件 |

## 4.2 分词、填充与批量张量

```python
from transformers import AutoTokenizer

model_id = 'Qwen/Qwen2.5-0.5B-Instruct'
tokenizer = AutoTokenizer.from_pretrained(model_id)
batch = tokenizer(['你好', '请解释矩阵乘法'], padding=True,
                  truncation=True, max_length=64, return_tensors='pt')
assert batch['input_ids'].shape == batch['attention_mask'].shape
text = tokenizer.decode(batch['input_ids'][0], skip_special_tokens=True)
```

这段及后续加载检查点的代码需要网络或已有缓存，首次运行会下载资产；模型示例用于讲解接口，不代表推荐其作为最新最强模型。`padding=True` 补齐到当前批次最长序列，`padding='max_length'` 补齐到指定长度；`truncation=True` 会丢弃超长输入，必须确认关键证据是否被截去。

`max_length` 在分词时限制输入长度，在生成时通常限制总序列长度；生成更宜使用 `max_new_tokens` 明确新增 token 的预算。批量生成的 decoder-only 模型通常采用左填充，应依据检查点说明设置 `tokenizer.padding_side='left'`，并传入正确的 attention mask。

## 4.3 聊天模板与确定性生成

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

model_id = 'Qwen/Qwen2.5-0.5B-Instruct'
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id)
model.eval()
messages = [{'role': 'user', 'content': '用一句话解释梯度。'}]
prompt = tokenizer.apply_chat_template(messages, tokenize=False,
                                       add_generation_prompt=True)
inputs = tokenizer(prompt, add_special_tokens=False, return_tensors='pt')
with torch.no_grad():
    output_ids = model.generate(**inputs, max_new_tokens=64, do_sample=False)
new_ids = output_ids[:, inputs['input_ids'].shape[1]:]
answer = tokenizer.batch_decode(new_ids, skip_special_tokens=True)[0]
```

模板先产生文本，再分词时用 `add_special_tokens=False`，避免重复添加模板已包含的特殊符号。也可直接让模板返回 token。模板由检查点定义，角色分隔符和 assistant 起始标记属于训练格式的一部分。

上例选择 CPU 默认路径便于理解。单设备 GPU 可先 `model.to(device)`，再对输入字典逐项 `.to(device)`；大模型可用 `device_map='auto'` 分配设备，此时不要再盲目对整个模型调用 `.to(...)`。新版本常用 `dtype='auto'`，旧版本常见 `torch_dtype`，应按已安装版本的文档选择；自动设备映射还依赖相应运行组件。

| 参数 | 含义 | 使用边界 |
| --- | --- | --- |
| `do_sample=False` | 按配置执行非采样解码；默认单束为贪心 | 不代表跨硬件逐位一致 |
| `do_sample=True` | 从截断或调整后的分布采样 | 此时 temperature、top_p 等才有相应意义 |
| `temperature` | 调整采样分布锐度 | 不是知识准确率开关 |
| `top_p` | 保留累计概率达到阈值的候选集合 | 与采样策略共同解释 |
| `max_new_tokens` | 新生成 token 数上限 | token 数不等于中文字数 |
| `eos_token_id` | 结束标记 | 应尊重检查点已有配置 |
| `use_cache=True` | 复用自回归 KV 状态 | 降低重复计算但消耗显存 |

## 4.4 attention mask、因果掩码与 labels

![三种掩码与监督边界](/syntax-hf-labels.png)

三者回答不同问题：attention mask 标出有效输入位置；因果掩码禁止看到未来 token；labels 中的 -100 通常让损失忽略某些位置。把提示词标签置为 -100 不代表提示词不能被模型读取。

```python
import torch
from transformers import GPT2Config, GPT2LMHeadModel

# 无需下载权重：随机小模型，只验证接口和损失形状。
config = GPT2Config(vocab_size=32, n_positions=16, n_embd=16, n_layer=1, n_head=2)
model = GPT2LMHeadModel(config)
input_ids = torch.tensor([[4, 5, 6, 7, 0]])
attention_mask = torch.tensor([[1, 1, 1, 1, 0]])
labels = input_ids.clone()
labels[attention_mask == 0] = -100
labels[:, :2] = -100           # 提示词不计入损失，仍可作为条件
out = model(input_ids=input_ids, attention_mask=attention_mask, labels=labels)
assert out.logits.shape == (1, 5, 32)
assert torch.isfinite(out.loss)
out.loss.backward()
```

常见 causal LM 的 forward 会在内部对齐下一 token 预测与标签，不能再手工移位一次。若 pad 与 eos 使用同一 ID，应根据 attention mask 屏蔽填充位置，而不是把所有等于该 ID 的标签一并屏蔽，否则真实 EOS 监督也会消失。

# 5. 线性代数

## 5.1 向量、矩阵与批量计算

矩阵乘法不是逐元素乘法：$X_{B\times d}W_{d\times h}=H_{B\times h}$，其中 $H_{ij}=\sum_kX_{ik}W_{kj}$。被求和的 d 轴是输入特征轴，输出 h 轴是新的表示空间。

![矩阵乘法的形状与几何解释](/basics-linear.png)

图中 d 的对齐解释了为什么维度必须匹配。几何上，线性映射能够旋转、缩放、剪切并压缩空间；加上偏置才是仿射映射。批量运算同时处理多个样本，但每行仍共享同一组权重。

## 5.2 范数、秩与奇异值分解

向量 L2 范数测长度，矩阵 Frobenius 范数测所有元素的平方和；谱范数衡量最大方向放大倍数。矩阵的秩描述独立方向数，而不是矩阵中非零元素的数量。

奇异值分解 $W=U\Sigma V^\top$ 把变换拆成旋转、轴向缩放、再旋转。保留最大的 r 个奇异值可得到低秩近似，但只有当被舍弃方向对任务影响小，压缩才有意义。极不均衡的奇异值会让优化在不同方向上速度悬殊。

## 5.3 线性代数的最小代码

```python
import numpy as np

x = np.array([[1., 2.], [3., 4.]])
w = np.array([[1.], [-1.]])
assert np.array_equal(x @ w, [[-1.], [-1.]])
u, s, vh = np.linalg.svd(x, full_matrices=False)
assert np.allclose((u * s) @ vh, x)
a = np.array([[3., 1.], [1., 2.]])
b = np.array([9., 8.])
solution = np.linalg.solve(a, b)
assert np.allclose(a @ solution, b)
```

解线性方程优先 `solve(A,b)`，不必显式计算 `inv(A) @ b`；非方阵最小二乘可用 `np.linalg.lstsq(A,b,rcond=None)`。`np.linalg.norm(x, ord='fro')` 是矩阵 Frobenius 范数，`ord=2` 是谱范数，不能把它们都解释为逐元素平方和。PyTorch 的 `torch.linalg.solve`、`torch.linalg.svd` 提供对应接口并可接入自动微分，但退化奇异值附近的导数需要谨慎。


# 6. 微积分

## 6.1 导数、偏导与梯度

导数描述局部变化率。多变量标量函数的梯度 $\nabla f$ 汇总各坐标偏导；一阶近似为 $f(x+\Delta)\approx f(x)+\nabla f(x)^\top\Delta$。在欧氏距离约束下，负梯度是局部最陡下降方向。

偏导要保持其他自变量不变；神经网络中同一变量可能通过多条路径影响损失，因此总梯度要把各路径贡献相加。可微不等于梯度处处有用：饱和区域虽可导，梯度仍可能极小。

## 6.2 链式法则与方向导数

对复合函数 $y=f(g(x))$，链式法则把局部导数相乘；方向导数为 $\nabla f(x)^\top v$。梯度是一个向量，方向导数是选定方向上的一个标量。

中心差分 $[f(x+\epsilon v)-f(x-\epsilon v)]/(2\epsilon)$ 可用于检查解析梯度。过大的步长产生截断误差，过小的步长放大浮点误差；验证时优先使用双精度与平滑测试点。

## 6.3 用中心差分验证方向导数

```python
import numpy as np

def f(x):
    return np.sum(x ** 2)

x = np.array([1., 2.], dtype=np.float64)
v = np.array([3., 4.], dtype=np.float64)
v /= np.linalg.norm(v)
eps = 1e-5
finite_difference = (f(x + eps * v) - f(x - eps * v)) / (2 * eps)
analytic = (2 * x) @ v
assert np.allclose(finite_difference, analytic, rtol=1e-6, atol=1e-8)
```

这里方向向量归一化后，结果是沿单位方向的变化率。`**` 表示幂，`@` 表示内积或矩阵乘法；Python 的 `^` 是按位异或，不能写成平方。差分用于小规模数值检查，不应代替大模型训练中的反向传播。


# 7. 自动微分

## 7.1 计算图、反向模式与梯度累积

自动微分记录实际执行的运算，并组合它们的局部导数。深度学习通常有许多参数、一个标量损失，反向模式可以高效得到所有参数梯度。

![从平方与乘法节点理解反向传播](/basics-autograd.png)

图中 $u=x^2,y=3u$，因此 $dy/dx=6x$；x=2 时梯度为 12。反向从 y 出发，不需要用微小扰动逐个试探参数。梯度默认可以累加，连续调用反向而不清零会改变有效更新。实现细节参见 [PyTorch 自动微分说明](https://docs.pytorch.org/docs/stable/notes/autograd.html)。

## 7.2 detach、no_grad 与梯度检查

no_grad 适用于不需要构建反向图的计算；detach 用于切断某条张量依赖。二者都不能替代 model.eval：后者控制 Dropout、BatchNorm 等模块的运行行为，不负责关闭自动微分。

梯度检查先比较单个小模块，再接入完整网络。原地修改、非光滑点、随机层、低精度都会让差分检查变得不可靠。冻结某个参数并不代表可以截断通过该层传向更早参数的梯度。

## 7.3 backward、grad 与高阶导数

```python
import torch

x = torch.tensor(2., dtype=torch.float64, requires_grad=True)
y = 3 * x ** 2
g, = torch.autograd.grad(y, x, create_graph=True)
h, = torch.autograd.grad(g, x)
assert g.item() == 12 and h.item() == 6
assert x.grad is None  # grad 返回结果，不向叶子 .grad 累积
z = torch.tensor([1., 2.], dtype=torch.float64, requires_grad=True)
ok = torch.autograd.gradcheck(lambda t: (t ** 3).sum(), (z,))
assert ok
```

| 接口 | 结果 | 常见误区 |
| --- | --- | --- |
| `loss.backward()` | 向叶子参数的 `.grad` 累积 | 默认不是覆盖旧梯度 |
| `torch.autograd.grad(y, x)` | 返回梯度元组 | 不等于优化器更新 |
| `create_graph=True` | 为求导过程继续建图 | 高阶导数需要，普通训练通常不需要 |
| `retain_graph=True` | 保留供再次反向使用的图 | 不会自动构建高阶导数图 |
| `y.backward(v)` | 计算向量与 Jacobian 的乘积 | 非标量输出需要指定上游梯度 |
| `torch.no_grad()` | 关闭上下文内通常的梯度记录 | 不会自动关闭 Dropout |

梯度累积可用于用多个微批次模拟更大批次。若各微批大小相同且 loss 已取均值，可将每次 loss 除以累积步数再反向；末尾不满一组、不同批大小和分布式同步都需单独处理。


# 8. 概率论

## 8.1 条件概率、贝叶斯公式与期望

条件概率 $P(A\mid B)=P(A,B)/P(B)$ 描述在已知 B 后的不确定性；贝叶斯公式把似然与先验结合为后验。期望是按概率加权的平均，方差刻画围绕均值的波动。

![联合、条件、期望与负对数似然](/basics-probability.png)

图中的条件化相当于缩小观察范围，然后重新归一化概率。期望不一定是一个可能实际出现的样本：掷骰子的期望 3.5 并不是某个骰面。机器学习中的预测分布也需要用长期频率与任务损失来检验。

## 8.2 似然、熵与交叉熵

固定参数看数据得到概率，固定数据看参数得到似然。最大似然等价于最小负对数似然；对独立样本，乘积变成求和，便于优化。

熵 $H(p)=-\sum_i p_i\log p_i$ 衡量分布自身的不确定性；交叉熵 $H(p,q)=-\sum_i p_i\log q_i$ 衡量用 q 描述 p 的代价。两者之差为 KL 散度。对独热标签，交叉熵就是正确类别概率的负对数，错误且自信的预测受到更大惩罚。

## 8.3 采样、对数概率与稳定交叉熵

```python
import numpy as np
import torch
import torch.nn.functional as F

rng = np.random.default_rng(7)
samples = rng.choice([0, 1], size=10000, p=[0.7, 0.3])
empirical_mean = samples.mean()
logits = torch.tensor([[1000., 1001., 999.]], dtype=torch.float64)
target = torch.tensor([1])
log_probs = F.log_softmax(logits, dim=-1)
loss = F.cross_entropy(logits, target)
assert torch.allclose(loss, -log_probs[0, 1])
dist = torch.distributions.Categorical(logits=logits)
assert torch.allclose(dist.log_prob(target), log_probs[:, 1])
```

直接 `exp(1000)` 会溢出；稳定的 log-softmax 会在内部采取数值稳定处理。概率密度可能大于 1，离散类别概率才要求每项不超过 1 且总和为 1。抽样均值随样本量波动，不应断言每次都精确等于理论期望。独立生成器减少全局随机状态之间的干扰。


# 9. 学习闭环

## 9.1 一个最小可复现实验

建立可复现实验时，保存数据划分、随机种子、软件版本、模型配置、优化器状态与指标定义。随机种子控制部分随机性，但跨设备、跨算子版本的逐位一致仍需额外条件。

建议用人工合成数据 $y=2x_1-3x_2+1+\epsilon$ 验证整个流水线。若线性模型无法逼近真实系数，先排查标准化、形状广播和更新逻辑；随后再引入真实数据的不确定性。

## 9.2 精度、编译与现代计算工具

精度与速度需要共同考虑：低精度矩阵乘法可能更快，但归约、概率归一化和小数差分对误差更敏感。混合精度通常让不同算子使用不同 dtype，而不是把所有张量粗暴转换成同一种低精度。

编译、算子融合和异步 GPU 执行改变执行方式，不改变数学目标；初次编译时间应与稳态时间分开报告。读完本章应能用形状、梯度、概率三个视角解释一次参数更新，并辨认数据错误与优化错误。

## 综合算例：从形状到梯度

设 $X=\begin{bmatrix}1&2\\3&4\end{bmatrix}$，$w=(1,-1)^\top$，b=0，则预测为 $(-1,-1)^\top$。若目标为 $(0,1)^\top$，采用批量平均的半平方损失，残差为 $(-1,-2)^\top$，$L=(1+4)/4=1.25$。

因此 $\nabla_wL=X^\top r/2=(-3.5,-5)^\top$，偏置梯度为 -1.5。学习率 0.1 更新后，w=(1.35,-0.5)，b=0.15。新预测为 (0.5,2.2)，损失变为 0.4225；这里下降成立是具体算例，不代表任意步长都保证下降。

## 自检问题

如果把目标从 [2,1] 改成 [2]，广播后的残差形状是什么？如果连续反向两次但只更新一次，梯度如何变化？如果把 X 的第二列单位扩大一千倍，原学习率为什么可能不再合适？这些问题分别检查形状语义、梯度状态和优化尺度。

## 9.3 用合成回归闭合学习流程

```python
import torch
from torch import nn

torch.manual_seed(7)
x = torch.randn(256, 2)
y = 2 * x[:, 0:1] - 3 * x[:, 1:2] + 1
model = nn.Linear(2, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
for step in range(200):
    optimizer.zero_grad(set_to_none=True)
    prediction = model(x)
    assert prediction.shape == y.shape
    loss = (prediction - y).square().mean()
    loss.backward()
    optimizer.step()
assert torch.allclose(model.weight.detach(), torch.tensor([[2., -3.]]), atol=1e-3)
assert abs(model.bias.item() - 1) < 1e-3
```

这段故意使用无噪声数据，以验证模型和更新语法；真实评估必须加入独立验证或测试数据。检查点可保存 `model.state_dict()` 与 `optimizer.state_dict()`；记录 `torch.__version__`、`np.__version__`、`pd.__version__`，比只写“运行成功”更有复现价值。

CUDA 混合精度可用 `torch.autocast(device_type='cuda', dtype=torch.bfloat16)` 包住前向与损失，硬件须支持相应精度；float16 训练常配合 GradScaler。`torch.compile(model)` 应在基础结果正确后尝试，分别记录编译耗时与热身后的性能。计时 GPU 运算时须考虑异步执行，例如在计时边界调用 `torch.cuda.synchronize()`；否则测到的可能只是提交任务的时间。
