# 1. 序列模型

## 1.1 自回归分解与隐状态

序列模型利用顺序中的依赖。自回归分解 $p(x_{1:T})=\prod_tp(x_t\mid x_{<t})$ 是概率链式法则；具体模型决定如何表示历史。RNN 用隐状态压缩前缀：$h_t=\phi(W_xx_t+W_hh_{t-1}+b)$。

![循环单元沿时间展开](/rnn-unroll.png)

图中每个时刻使用同一组参数，不是为每个位置训练不同网络。隐状态既是信息通道，也是压缩瓶颈；长度增加时，远处细节可能被覆盖。序列长度不直接增加参数量，却增加计算和训练激活。

# 2. 文本预处理

## 2.1 分词、词表与序列批次

分词把文本转换为 token，词表把 token 映射为索引。字符、词和子词在词表规模、长度和未登录词之间取舍。分词器应与模型一起保存，否则同一个索引可能被解释为不同文本。

![输入与下一词标签的错位关系](/rnn-language.png)

图中标签相对输入向前移一位，用过去预测下一项。随机抽取子序列时应重置隐状态；连续分块时可传递状态，但通常要切断跨块计算图，避免无限增长。padding 和句子边界也需正确处理。

# 3. 马尔科夫假设

## 3.1 有限记忆与状态充分性

一阶马尔科夫假设是未来在给定当前状态后与更早历史条件独立；n 元语法则使用有限长度的可见上下文。RNN 的隐状态尝试汇总历史，不等于只看前一个词。

“状态足够充分”是建模目标，不是天然事实。若任务需要精确回忆很久之前的罕见信息，小状态可能不足；扩大状态、引入检索或显式注意力是不同补救方式。

# 4. n 元语法

## 4.1 计数、平滑与困惑度

n 元语法从计数估计条件概率，未出现的组合会得到零概率，因此需要平滑或回退。上下文越长，组合越稀疏，统计可靠性与表达能力发生冲突。

困惑度为 $\operatorname{PPL}=\exp(-\frac1T\sum_t\log p(x_t\mid x_{<t}))$。它是平均负对数似然的指数，越低越好；不同分词器的 token 粒度不同，PPL 通常不能直接横向比较。

# 5. 循环神经网络

## 5.1 参数共享与时间展开

RNN 每步把新输入与旧状态合并，再产生当前输出。参数共享使它适合变长序列，但标准递推沿时间存在依赖，不能像完全并行的前馈层那样同时完成所有时刻。

批量训练应区分 batch 轴、time 轴和feature 轴。多个独立序列之间不能错误共享状态；若打乱 batch 内样本顺序却继续使用旧状态，会把不同样本的历史接在一起。

## 5.2 BPTT、截断与梯度裁剪

BPTT 把展开后的网络视为深计算图，从末端向前传播梯度。隐藏状态 Jacobian 连乘使长程梯度可能消失或爆炸，梯度裁剪主要限制爆炸，不能恢复已经消失的信息。

截断 BPTT 只在有限窗口内反向。窗口外的状态值仍可传递，但跨边界的梯度被截断，因此它改变了学习信号可到达的范围。比较方法时应记录截断长度与状态重置策略。

# 6. GRU

## 6.1 更新门与重置门

GRU 用重置门控制旧状态如何参与候选状态，用更新门控制新旧信息混合。采用一种常见约定：$h_t=(1-z_t)\odot h_{t-1}+z_t\odot\tilde h_t$；有些文献把 z 的含义反过来，阅读时先核对公式。

![GRU 与 LSTM 的信息通路](/rnn-gates.png)

图左没有独立细胞状态，图右为 LSTM 保留了 c 通道。门控是逐元素连续值，不是只能开或关的硬开关；它让不同状态维度学习不同时间尺度。

# 7. LSTM

## 7.1 细胞状态与三道门

LSTM 的关键更新为 $c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t$，再由 $h_t=o_t\odot\tanh(c_t)$ 读出。遗忘门决定保留，输入门决定写入，输出门决定暴露多少内部状态。

加性细胞路径改善长程信息传递，但遗忘门持续小于 1 时，信息仍会逐渐衰减。LSTM 比基础 RNN 参数更多、每步计算更重；在短序列或数据较少时，应与简单基线比较。

# 8. 双向循环神经网络

## 8.1 双向上下文与因果限制

双向 RNN 同时处理正向和反向序列，再组合两侧状态，适合已知完整输入的标注、编码和分类。它能利用未来上下文，但不能直接用于严格在线的下一步预测。

评估流式任务时，反向分支若看到未来样本就会泄漏。离线语音识别和实时语音识别的可用信息不同，不能只比较相同网络名称而忽略延迟与上下文限制。

# 9. 编码器—解码器架构

## 9.1 状态传递、teacher forcing 与曝光偏差

编码器把源序列转换为表示，解码器条件生成目标。基础版本把源信息压缩为固定上下文，长输入可能形成瓶颈；注意力允许每步重新读取源位置。

![编码—解码与束搜索候选树](/rnn-seq2seq.png)

训练时 teacher forcing 使用真实前缀，推理时使用模型自己的前缀，形成曝光偏差。直接减少 teacher forcing 不必然改善结果，因为它也会改变训练目标；应通过完整序列质量而非单步准确率验证。

# 10. 束搜索

## 10.1 候选扩展、长度偏置与采样

束搜索每步扩展当前候选，按累计对数概率保留前 k 条。它近似寻找高概率序列，不保证全局最优；更大的束也不必然提高人工质量。

短序列的对数概率通常较少累积负值，可能受到偏爱，因此需要明确终止规则与长度归一化。随机采样则面向分布多样性，temperature、top-k、top-p 改变采样分布，不能与确定性搜索混为一谈。

# 11. 现代序列模型

## 11.1 状态空间、Mamba 与选择性记忆

状态空间模型通过状态递推表示序列动态。Mamba 让部分状态更新参数依赖当前输入，从而选择保留或忽略哪些信息；这与所有 token 都使用固定转移的线性递推不同。

![固定递推与输入相关的选择性更新](/rnn-ssm.png)

图中的固定大小状态有利于控制解码缓存，但它要压缩历史；注意力则显式保留可读取的 KV。两类方法在检索、长程结构和硬件效率上存在任务相关取舍。[Mamba 原论文](https://arxiv.org/abs/2312.00752)。

## 11.2 Mamba-2／3 与架构选择

Mamba-2 通过结构化状态空间对偶性联系状态空间与部分注意力计算，重点包括可高效执行的结构。[论文](https://arxiv.org/abs/2405.21060)。2026 年 Mamba-3 进一步讨论更丰富的离散化、复值状态与多输入多输出形式，关注推理效率。[ICLR 2026 论文](https://proceedings.iclr.cc/paper_files/paper/2026/hash/8abd2043b71a074278d5f687947bff9c-Abstract-Conference.html)。

架构选择应同时测试长程检索、真实任务质量、训练吞吐和不同长度的解码成本。有限状态并非“免费记住无限上下文”，注意力的显式缓存也并非所有任务都值得付出。

## 综合算例：门控如何延长记忆

忽略新写入时，LSTM 的细胞路径满足 $c_T=(\prod_tf_t)c_0$。若每步遗忘门固定为 0.9，经过 50 步只保留约 0.0052；若固定为 0.99，则约为 0.605。门控能够调节时间尺度，却不是永久无损存储。

真实网络中门依赖输入与状态，完整梯度还包含其他路径；上述算例只用于解释直接细胞路径的衰减。它提示为什么需要测试不同延迟长度，而不是只在一个序列长度上报告结果。

## 长程记忆实验

构造“开头给一个符号，中间插入干扰，末尾要求回忆”的任务，逐步延长干扰区间。分别比较 RNN、GRU、LSTM 与注意力基线，并固定参数量或训练预算。记录准确率、训练耗时和解码状态大小，避免把更大模型的容量收益误认为结构优势。
