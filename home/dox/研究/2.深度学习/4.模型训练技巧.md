# 0. 数据预处理

## 0.1 划分、清洗与训练集统计量

数据划分决定结果能回答什么问题。随机划分适合近似独立同分布样本；按用户、设备、病人分组能检验新实体泛化；按时间划分更接近未来预测。去重应考虑近重复图像和同一事件的多个切片。

![先划分，再拟合预处理](/training-split.png)

图中标准化统计量只来自训练集，再被应用于三个子集。若先用全数据选择特征或填充缺失值，测试分布已间接参与建模。所有清洗规则、排除条件和数据版本都应可追溯。

## 0.2 数据增强与任务语义

增强必须保持任务语义：水平翻转可能适合普通物体分类，却不适合左右手识别；随机裁剪可能删除决定标签的小目标。增强强度不是越大越好，应与真实测试变化对应。

训练增强和评估预处理分开管理。Mixup 等方法同时混合输入和目标，其损失语义与普通增强不同；时序任务还要避免增强破坏因果顺序或传感器同步。

# 1. 前向传播

## 1.1 预测、损失与批量聚合

前向计算预测和损失。批量均值、样本权重和有效 token 数决定梯度规模；不同长度样本若各自先求均值再平均，与对所有 token 求平均并不等价。

![前向数值流与反向梯度流](/training-graph.png)

图中损失是计算图的终点，但不是更新参数的动作。检查前向时，逐层记录均值、标准差、最大值和有限值比例，比只盯最后一个 loss 更容易定位异常。

# 2. 反向传播

## 2.1 链式求导、梯度累积与清零

反向传播按链式法则累积各路径导数。梯度累积把多个微批次的贡献合并后再更新；等大小微批次通常将各次损失除以累积步数，以保持与大批量均值一致。

不等长序列应按有效 token 数加权，否则短序列和长序列的相对权重会改变。参数更新后清零梯度；梯度裁剪应在累积完成后执行。批归一化和随机层会让微批次累积与真正大批量存在差异。

# 3. 计算图

## 3.1 动态图、叶子张量与检查点

动态计算图由实际执行的运算构成，条件分支会影响当次图结构。叶子参数接收优化器更新，中间激活主要承担链式求导的桥梁。保留不必要的图会扩大显存占用。

激活检查点保存较少中间量，在反向时重算部分前向，以计算换显存。随机数状态、重算一致性和副作用都需要留意；它不减少模型参数或优化器状态本身。

# 4. 欠拟合与过拟合

## 4.1 学习曲线与误差分解

训练和验证误差都高，可能是容量不足、特征不充分或优化失败；训练低而验证高，更像过拟合、分布差异或泄漏后的评估错觉。

![三种典型学习曲线](/training-fit.png)

图是诊断示意，不是根据曲线即可唯一确定病因。训练损失含 Dropout 或增强、验证损失不含时，两者甚至可能倒挂。比较曲线前先统一是否含正则项、数据处理方式与平均分母。

## 4.2 模型选择、早停与实验控制

早停在验证指标长期不改善时停止，并恢复验证最优的权重，而非直接使用最后一步。耐心值、评估频率和指标噪声应匹配：评估越频繁，不代表独立证据越多。

多次调参会逐渐适应验证集。最终测试应尽量只做一次确认；如果持续根据测试结果修改模型，它实际上已成为验证集。小数据场景可以使用嵌套交叉验证控制模型选择偏差。

# 5. 权重衰减

## 5.1 L2 正则与解耦衰减

普通 SGD 下，向损失加入 $\lambda\|\theta\|^2/2$ 会产生 $\lambda\theta$ 梯度，与相应的乘法衰减对应。自适应优化器会按坐标缩放梯度，因此把 L2 项放进梯度通常不等于独立衰减权重。

![权重衰减与随机失活](/training-regularization.png)

图左限制权重尺度，图右扰动训练时的子网络，二者作用不同。AdamW 将衰减与自适应梯度更新分离；偏置和归一化参数是否衰减，应明确记录而非依赖隐含默认值。[AdamW 原论文](https://arxiv.org/abs/1711.05101)。

# 6. Dropout

## 6.1 训练时随机失活与推理缩放

采用 inverted dropout 时，训练输出为 $h'=mh/(1-p)$，其中 m 以概率 1-p 取 1；推理时使用完整 h，不再做同样随机失活。缩放保持单个激活的期望，但不保证整个非线性网络的输出期望完全不变。

Dropout 强度应与数据量和模型容量匹配。评估忘记切换模式会让预测随机；反之，训练时长期处于 eval 模式会使设计中的正则化失效。

# 7. 梯度消失与梯度爆炸

## 7.1 初始化、归一化与残差

深层链式求导反复相乘，容易放大或缩小梯度。初始化应与激活函数配合；归一化调节中间尺度；残差提供较短的梯度路径。它们缓解问题，却不能替代合理学习率和输入尺度。

![稳定训练工具与低秩更新](/training-stability.png)

图中的四个检查点应逐项验证：先观察激活和梯度统计，再决定使用哪种工具。对序列模型，截断反向还改变了可学习的依赖范围；它不仅是节省显存的工程技巧。

## 7.2 梯度裁剪、混合精度与稳定性

全局范数裁剪将 g 缩放为 $g\min(1,c/\|g\|)$，保持方向但限制幅度。若几乎每一步都严重裁剪，可能需要降低学习率或排查异常数据，而不是继续压低阈值掩盖问题。

混合精度中先对梯度解除缩放，再裁剪。FP16 可能需要动态损失缩放；BF16 的指数范围更宽，但有效精度仍有限。发现 NaN 时检查输入、除零、指数溢出和归约，必要时对敏感算子恢复更高精度。

# 8. 分布偏移

## 8.1 协变量、标签与概念偏移

协变量偏移是输入分布改变而条件关系近似保持；标签偏移是类别先验改变；概念偏移是输入到标签的关系改变。这些是分析框架，真实问题常同时存在多种变化。

评估应按时间、地区、设备等切片。重要性加权只有在密度比可估计且支持集有足够重叠时才可靠；测试中出现训练完全未见的区域，单靠重加权无法补充知识。

# 9. K 折交叉验证

## 9.1 分组、时间序列与嵌套评估

K 折验证轮流留出一折，其余用于拟合；预处理也要在每个训练折内重新拟合。分组数据必须保持组完整，时间序列应使用向前验证，不能让未来记录进入过去的训练集。

嵌套验证用内层选择超参数、外层估计选择流程的泛化。报告均值之外，给出折间波动和样本量；相关样本很多时，折数增加不等于有效独立证据同比增加。

# 10. 现代训练实践

## 10.1 参数高效微调与 LoRA

LoRA 将更新限制为 $\Delta W=BA$，其中秩 r 远小于输入和输出维度，只训练两个小矩阵而冻结原权重。它减少可训练参数和相应优化器状态，但前向仍需使用基础模型。

目标层、秩、缩放系数、学习率与数据覆盖共同决定效果。低秩假设适合某些任务适配，不保证与全量微调等价。量化基础权重又引入独立误差，应分别验证。[LoRA 原论文](https://arxiv.org/abs/2106.09685)。

## 10.2 训练检查清单与失败诊断

排查顺序建议固定为：数据与标签 → 形状与损失 → 单批拟合 → 梯度与更新 → 全量训练 → 泛化。每一步保留一个能够反证当前假设的小实验。

| 现象 | 优先检查 | 有效对照 |
| --- | --- | --- |
| 损失完全不变 | 参数未注册、梯度被切断 | 查看参数更新量 |
| 突然出现 NaN | 异常 batch、溢出、步长 | 重放失败 batch |
| 训练好、验证差 | 划分、容量、分布偏移 | 降低容量并查近重复 |
| 恢复后曲线跳变 | 优化器、调度器、随机状态 | 比较不中断运行 |

实验记录应包括失败结果。只保留成功配置，会失去判断哪些因素真正重要的证据。

## 综合算例：不等长微批次的损失

微批次 A 有 10 个有效 token，平均损失 1；B 有 30 个有效 token，平均损失 3。直接平均两个均值得到 2，而全局 token 平均为 $(10\times1+30\times3)/40=2.5$。二者优化的样本权重不同。

梯度累积、分布式平均和 padding mask 都会遇到同一问题。正确做法是先明确希望每个 token 等权还是每个序列等权，再选择分母；没有脱离任务语义的唯一正确平均方式。

## 实验日志最小字段

保存配置、数据版本、训练步数、学习率、各项损失、梯度范数、有效 token 数与验证指标。出现异常时额外保存失败 batch 的可追溯标识。比较曲线应使用相同横轴：epoch、step、token 和墙钟时间各自回答不同问题。
