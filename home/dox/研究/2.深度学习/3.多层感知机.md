# 1. 模型架构

## 1.1 隐藏层与非线性表达

MLP 在仿射层之间插入非线性：$H=\sigma(XW_1+b_1)$，$Z=HW_2+b_2$。没有激活函数，多层仿射映射仍能合并为一个仿射映射，深度不会自动增加表达能力。

![多层感知机逐层形成表示](/mlp-network.png)

图中每层把上层特征重新组合。输入层不算有可学习变换的隐藏层；输出层的形式由任务决定，例如回归输出实数，单标签分类输出 logits。隐藏单元并不保证各自对应人类可命名的概念。

## 1.2 XOR：线性模型的边界

XOR 的同类点位于正方形对角，单条直线无法把两类完全分开。隐藏层可以先构造多个半空间特征，再组合出非线性区域。

![XOR 在原空间与隐藏表示中的变化](/mlp-xor.png)

图要表达的是“先改变表示，再做简单判别”。这不是说任意随机隐藏层都能分好 XOR，而是说明存在合适参数。训练是否找到这些参数，还受初始化、损失曲面与学习率影响。

## 1.3 宽度、深度与参数量

输入维 d、隐藏维 h、输出维 k 的单隐藏层网络含 $dh+h+hk+k$ 个参数。增加宽度扩展并行特征，增加深度允许复用中间计算；二者的计算、内存与优化代价不同。

普适逼近定理是存在性结果，不承诺有限数据下的泛化、实际所需宽度或训练可达性。选择容量应结合验证误差、训练成本和结构先验，而不是只比较参数总数。

## 1.4 前向实现与形状检查

批量特征通常为 [B,d]，线性层输出 [B,h]，激活不改变形状，最终 logits 为 [B,k]。图像展平时要保留 B 轴；把整个批次展成一个向量，会破坏样本独立性。

实现后检查参数是否注册、梯度是否有限、模型能否拟合少量样本。对不含随机层的小模型，改变批次内其他样本不应改变某个样本的输出；BatchNorm 等依赖批次统计的模块则有不同语义。

# 2. 激活函数

## 2.1 Sigmoid 与 Tanh

Sigmoid 的值域是 (0,1)，适合表达独立事件的概率；Tanh 的值域是 (-1,1)，输出以零为中心。两者在绝对值很大的输入处饱和，导数接近零，深层连乘时可能削弱梯度。

![常见激活函数的形状](/mlp-activations.png)

比较图中的负半轴、零点附近斜率和大正输入区间。激活函数并非越光滑越好：它要与初始化、归一化及优化设置配合。隐藏层使用 Sigmoid 与输出概率使用 Sigmoid，是两个不同设计问题。

## 2.2 ReLU 与 Leaky ReLU

ReLU 定义为 $\max(0,x)$，正半轴保留恒定梯度，计算简单。负半轴梯度为零，若某个单元长期落在负区间，可能不再获得有效更新。

Leaky ReLU 为负半轴保留小斜率。它缓解完全失活，但不保证网络就能稳定训练。较大的学习率、不合适的偏置初始化和异常输入尺度，都可能让激活分布偏离设计范围。

## 2.3 GELU、SiLU 与 SwiGLU

GELU 可写为 $x\Phi(x)$，SiLU 为 $x\sigma(x)$，它们在零点附近平滑地调节输入。SwiGLU 则把一条经过 SiLU 的分支与另一条线性分支逐元素相乘，再投影回模型维度。

![门控前馈与稀疏专家的区别](/mlp-gates.png)

图左是单个前馈块内部的门控，图右是路由器选择少量专家；二者不是同一种稀疏机制。门控层通常增加投影矩阵，比较时应匹配参数量和计算量。原始研究见 [GLU Variants Improve Transformer](https://arxiv.org/abs/2002.05202)。

# 3. 损失函数

## 3.1 回归：MSE、MAE 与 Huber

MSE 对大误差施加强惩罚；MAE 对异常值更稳健，但零点不可微；Huber 在小误差时用平方、大误差时近似线性，兼顾平滑和抗异常能力。其阈值必须与目标量纲一起考虑。

![根据目标语义选择损失](/mlp-losses.png)

图中的连续标尺对应回归，不应先把连续值任意切成类别再声称解决了原问题。多目标回归还需处理单位差异：米与毫米的平方误差相差百万倍，未经缩放的求和会改变任务权重。

## 3.2 分类：交叉熵与多标签 BCE

单标签分类假设每个样本只属于一个互斥类别，使用 Softmax 交叉熵。多标签分类允许同时出现多个属性，通常对每个标签使用独立 Sigmoid 与 BCE。

BCE 的稳定实现应直接接收 logits，避免显式 Sigmoid 后对接近零的数取对数。多标签阈值可按类别选择，但必须在验证集上确定；缺失标签也不能自动当成负标签。

## 3.3 损失缩放、掩码与样本权重

变长序列的 padding、部分标注区域和无效传感器值应通过掩码排除。损失归一化应除以有效元素数，而非固定张量大小；不同长度分布下，分母会改变样本的实际权重。

类别权重与重采样都会改变训练目标，可能影响概率校准。多任务损失 $L=\sum_j\lambda_jL_j$ 的系数不仅控制重要性，也补偿各损失的数值尺度；应同时观察各任务梯度和最终指标。

# 4. 现代扩展与实验

## 4.1 残差前馈网络与稀疏专家

残差前馈块学习 $x+F(x)$，有利于跨层传递表示；MoE 通过路由让每个 token 只激活部分专家。总参数规模决定容量的一部分，激活参数规模更接近单次计算成本，但通信和路由也会影响真实速度。

MoE 还需处理负载不均、专家容量和路由稳定性。以 [DeepSeek-V3 技术报告](https://arxiv.org/abs/2412.19437) 为例，现代大模型把专家结构与训练系统共同设计；不能把某个系统的收益全部归因于“更多专家”。

## 4.2 容量、优化和泛化的对照实验

建议建立三个对照：固定参数量比较宽浅与窄深；固定训练预算比较激活；固定架构比较正则化强度。每次只改变一个主要因素，并同时记录训练损失、验证损失、耗时和显存。

若训练损失不下降，检查优化；训练好而验证差，检查泛化和划分；不同随机种子差异很大，报告均值与波动。网络能够记住数据，不代表它学到了稳定的规律。

## 综合算例：手工构造 XOR

对二进制输入，令 $h_1=\operatorname{ReLU}(x_1-x_2)$，$h_2=\operatorname{ReLU}(x_2-x_1)$，则 $h_1+h_2$ 恰好等于 XOR。原空间两个蓝点在隐藏空间合并到原点，两个粉点位于两条坐标轴；用 $h_1+h_2>0.5$ 即可分开。

这个例子明确给出了参数，而不是仅声称“隐藏层能够解决”。它也说明特征变换可以压缩不影响任务的差异：原来的 (0,0) 与 (1,1) 被映射为同一表示。

## 容量账本与实验

输入 20 维、隐藏 64 维、输出 10 维的网络有 $20\times64+64+64\times10+10=1994$ 个参数。把隐藏层加宽到 128 后，不仅参数增加，激活与矩阵乘法也增加。

用相同数据划分比较 16、64、128 个隐藏单元，记录最佳验证轮次与训练时间。若训练误差改善而验证误差无改善，应先审查数据与正则化，再决定是否继续扩容。
