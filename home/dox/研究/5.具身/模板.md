# 1. 具身研究笔记写作模板

## 1.1 使用方式

本文件是可复用的写作指南，不是某个模型的论文结论。复制为新的编号 Markdown 后，将章节内容替换成目标工作的研究笔记；现有研究页只显示 index.json 中登记的文章，因此模板不加入阅读列表。

一篇完整笔记建议覆盖：研究问题、输入输出、核心图、分步解释、训练数据、实验结果、局限与来源。模型名称、版本和资料核对日期都应明确。

## 1.2 组织架构

- 页面入口：home/pages/research.html。
- 分类清单：home/dox/研究/index.json。
- 正文目录：home/dox/研究/5.具身/。
- 配图目录：home/dox/研究/imgs/5.具身/。
- 渲染逻辑：home/assets/research.js，负责目录、表格、公式和图片路径转换。

# 3. 正文结构

## 3.1 概览与创新点

说明原方法遇到什么问题、新方法改变了哪一环，以及哪些部分仍沿用已有工作。不要只列“更快、更强、更通用”，应说明比较对象和适用设置。

## 3.2 方法论

定义观测、状态、动作、动作块和时间符号；再用一个具体抓放例子贯穿流程。公式后紧接变量解释。教学算例应明确标注，避免读者误以为是论文配置。

## 3.3 训练与实验

记录数据来源、任务划分、训练目标、模型版本、硬件、成功条件与评测次数。区分论文结果、自己的复现实验和计划中的实验；没有测量时，不填入模拟的成功率。

## 3.4 局限与失败分析

至少讨论数据覆盖、动作接口、时延和失败恢复。把“选错目标”“运动不准”“接触失败”“任务超时”分开，有利于定位问题。

# 4. 来源与发布检查

优先引用原论文、官方项目页、模型卡和源码。在对应结论附近放链接；网页会变化，建议保留核对日期与版本。

发布前检查目录可跳转、图像存在、表格完整、公式显示正常、没有空章节；新文章登记到 index.json 后，检查本地 HTTP 预览，再提交正文与图片。
