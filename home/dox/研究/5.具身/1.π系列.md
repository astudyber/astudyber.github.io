# 1. Pi0

## 1.1 概览

《$\pi_o$: A Vision-Language-Action Flow Model for General Robot Control》

> 机器人学习拥有巨大潜力，既能充分释放柔性、通用、灵巧机器人系统的全部能力，也有望解答人工智能领域部分最为根本性的难题。然而，想要让机器人学习达到真实世界系统实际可用所要求的通用化水平，会在数据、泛化能力与鲁棒性方面遭遇巨大阻碍。本文探讨通用机器人策略（即机器人基础模型）如何应对上述挑战，以及我们该如何为复杂、高灵巧度任务设计高性能的通用机器人策略。本文提出一种全新的流匹配架构，该架构基于预训练视觉‑语言模型（VLM）构建，能够继承互联网规模的语义知识。随后本文探讨如何利用来自多种灵巧机器人平台的大规模、多样化数据集训练该模型，平台涵盖单臂机器人、双臂机器人以及移动机械臂。我们从多个维度对模型开展评估：预训练后的零样本任务执行能力、遵循人类及高层 VLM 策略给出的语言指令的能力，以及通过微调习得新技能的能力。实验结果覆盖丰富多样的任务场景，包括叠衣物、桌面清理与纸箱组装等。



## 1.2 创新点

* 架构：以 VLM 作为骨干网络，使用流匹配（flow matching）生成连续动作。提出一种通用机器人策略网络。
* 支持跨本体，支持零样本泛化，本身是一个预训练模型
* VLM + 独立 Action Expert 双分支解耦设计
* Chunk 长时序动作生成，一次性预测一段动作



## 1.3 方法论

![image-20260916193446738](/image-20260916193446738.png)

* 参数量：总计3.3B
* 模型基于左侧三类数据进行训练：作者自己采集的数据；网络上图文预训练数据；Open X-Embodiment 开源跨机器人数据集
* 图像经过VIT(SigLIP)进行编码，得到视觉 token
* 文本经过Gemma文本 embedding，得到文本 token
* Gemma Transformer 主干，自注意力融合视觉和文本信息（不用交叉注意力原因：复用 Gemma减少训练量；图文直接拼成一个序列，互相可见，交叉注意力一般是单向可见，进行匹配用的）
* action expert 用的是 flow matching，其中 $q_t$代表 t 时刻机器人的 observation   以及 states 状态信息。
* 视觉，文本，状态等信息，全部送入 Action-Expert 通过带有掩码的自注意力进行信息融合，利用 block-causal （块因果掩码）控制信息流向，“动作看全部，VLM 不看机器人和动作”。（不用交叉注意力原因：复用flow matching 参数，简化实现，避免大量随机初始化交叉注意力参数，避免了增加模型参数量、训练难度；同时还能缓存本体状态的 KV 加速流匹配推理。）
* 图示中的 DoF 代表自由度，14/18一般是双臂机械臂，7/8一般是单臂。

# 2. Pi0-Fast

## 2.1 概览

《FAST: Efficient Action Tokenization for Vision-Language-Action Models》

> 自回归序列模型，例如基于 Transformer 的视觉‑语言‑动作（VLA）策略，在学习复杂且具备泛化能力的机器人行为方面效果十分突出。但这类模型需要对连续的动作信号做分词（令牌化），该分词方式决定了模型预测出的离散符号如何映射回机器人的连续动作。本文发现：现有的机器人动作分词大多采用**逐维度、逐时间步的简单分箱策略**，在基于高频机器人数据学习灵巧操作技能时，通常表现很差。 针对该问题，本文提出一种基于离散余弦变换的、面向机器人动作的全新压缩式分词方案，命名为**频域动作序列分词（FAST，Frequency‑space Action Sequence Tokenization）**。借助 FAST，我们可以针对高难度、高频灵巧任务训练自回归 VLA 模型，而这类任务上传统离散化方法会完全失效。



> 在 FAST 基础之上，我们发布通用机器人动作分词器 FAST+，该分词器在 100 万条真实机器人动作轨迹上完成训练，可作为黑盒组件适配各类不同动作空间、不同控制频率的机器人动作序列。最后实验表明：将 FAST 与$\pi_0$ VLA 模型结合后，可以在一万小时机器人数据集上开展规模化训练，性能能够比肩基于流匹配 / 扩散的 VLA 模型，同时训练耗时最多可降低 5 倍。



## 2.2 创新点

* 引入 FAST 频域动作分词，把动作转为离散 token，直接自回归预测，移除流匹配模块，训练速度提升 5 倍。精度有微小掉点。
* 由于自回归 Transformer 只能预测离散 token, 不能直接输出连续实数，所以需要分箱。机器人动作是**连续实数向量**（比如关节角度、笛卡尔坐标），无法直接作为 Transformer 输出。
* 简单分箱（Naive Binning）：先将关节角度缩放到 [-1, 1]，然后均匀切分成 256 格（连续值 --> 离散值）。这里属于无监督分箱。

![image-20260916202547771](/image-20260916202547771.png)

* DCT 离散余弦变换：即傅里叶变换的 [实数，偶函数，半区间] 的特殊形式。

  是一种**压缩方案**，把一段连续动作 chunk 从时域变换到频域；舍弃高频噪声分量，保留关键低频系数，再对 DCT 系数做分词。
