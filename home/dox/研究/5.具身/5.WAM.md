# 1. WAM：世界—动作模型

## 1.1 概览与术语

本篇中的 <font color='#2aa198'>WAM</font> 指 World–Action Model（世界—动作模型）：在动作学习中显式利用未来世界演化的建模。它是一类研究思路，不是所有团队共享的统一网络，也不是对所有“多模态机器人系统”的泛称。资料核对日期：2026-09-21。

> VLA 关注“现在该怎么动”；世界模型关注“接下来会发生什么”；WAM 尝试让两者之间建立更紧密的学习关系。具体方法可能预测视频、特征或潜在状态。

![世界—动作模型概念闭环：当前观测生成动作与未来预测，执行后获得真实反馈](/wam-loop.png)

图为 AI 辅助概念示意。两条输出分别表示动作与未来信息，并非要求每一种 WAM 在部署时都生成完整视频。“比较预测与现实”表示可设计的诊断环节，也不是所有论文都有的固定模块。

# 2. 方法论：三种基本建模问题

## 2.1 策略模型

用当前及历史观测 $o_{\leq t}$ 和指令 $l$，预测动作块 $A_t$，可记为 $p(A_t \mid o_{\leq t},l)$。动作块内含多个未来控制目标。

## 2.2 动作条件世界模型

给定观测和候选动作，预测未来观测：$p(o_{t+1:t+H} \mid o_{\leq t},A_t)$。它回答“如果这样动，会发生什么”。在模型规划中可比较多个候选，但动作范围与预测可靠性必须匹配。

## 2.3 联合世界—动作建模

一种教学表达是 $p(A_t,o_{t+1:t+H} \mid o_{\leq t},l)$。这表达学习对象，不限定网络必须如何分解或采样。

例如“把杯子放入托盘”：动作分支学习夹爪移动与松开；未来视觉监督帮助表示杯子、托盘和接触后的变化。仅凭视频里杯子最终出现在托盘中，仍无法保证对应关节命令可达或稳定。

# 3. 训练信号和推理路径

## 3.1 通用训练抽象

可把多目标学习写成 $L=\lambda_a L_{\mathrm{action}}+\lambda_w L_{\mathrm{world}}$。这里是教学抽象，不是某篇论文的完整损失函数。

- 动作项约束控制输出，可以是回归、分词预测、扩散或流匹配目标。
- 世界项约束未来信息，可以在像素空间或潜在空间计算。
- 两个权重控制优化侧重，不能仅凭损失数值大小判断哪个任务学得更好。
- 遮挡、接触、滑动等关键事件值得单独评估，背景纹理误差未必影响控制。

## 3.2 三种推理用法

| 方式 | 运行时做什么 | 主要代价 | 适合检查什么 |
| --- | --- | --- | --- |
| 预测后规划 | 比较多组动作的预测未来 | 候选数和滚动长度增加计算 | 模型误差是否被规划利用 |
| 视觉目标条件策略 | 先得到目标画面，再生成动作 | 额外目标生成模块 | 目标是否可达、是否歧义 |
| 训练联合、推理只动作 | 学习时利用未来监督，部署省去视频解码 | 依赖训练迁移效果 | 速度收益与控制表现 |

这里是概念分类，并非每一种实现都能直接互换。

# 4. 代表工作与阅读重点

## 4.1 GigaWorld-Policy

该工作强调 action-centered 的世界—动作建模，训练时学习视觉动态，支持高效动作解码和可选视频生成。理解重点是“未来监督有用”不必推出“每次执行前都要生成未来视频”。参见 [GigaWorld-Policy](https://arxiv.org/abs/2603.17240)。

## 4.2 GigaWorld-Policy-0.5

后续工作将动作条件世界建模与 WAM 训练混合，并通过专家分工减少动作推理中的活跃计算。论文中的设备时延应结合硬件、预测长度和计时范围阅读。参见 [GigaWorld-Policy-0.5](https://arxiv.org/abs/2607.13960)。

## 4.3 世界模型增强策略，不一定等同于 WAM

GigaBrain-0.5M⁎ 研究世界模型参与强化学习；π0.7 支持视觉子目标等引导方式。这些都说明世界预测能与策略结合，但不宜仅凭存在世界模型就给所有系统贴上同一架构标签。参见 [GigaBrain-0.5M⁎](https://arxiv.org/abs/2602.12099) 与 [π0.7 官方介绍](https://www.pi.website/blog/pi07)。

# 5. 一个抓放任务的教学流程

1. 读取桌面图像和当前夹爪状态。
2. 描述目标：“杯子稳定放在托盘内”。
3. 生成候选动作，必要时预测对应的未来状态。
4. 检查动作范围和候选的可达性，执行短片段。
5. 重新观测杯子是否随夹爪移动，决定继续、重抓或结束。

如果杯子滑落，上一轮预测的未来已经失效。继续按原动作播放，会让开环误差不断扩大；闭环必须使用真实反馈更新决策。

# 6. 评测：看起来合理与真正可用

| 评测层面 | 问题 | 示例检查 |
| --- | --- | --- |
| 视觉一致性 | 物体身份是否保持 | 杯子不能换颜色或凭空消失 |
| 动作一致性 | 未来变化是否由给定动作引起 | 静止动作不能让杯子飞走 |
| 物理可行性 | 接触、遮挡和支撑是否合理 | 杯子不能穿过桌面 |
| 任务表现 | 真机最终是否完成 | 放入托盘并稳定保持 |
| 系统效率 | 闭环周期是否满足任务 | 统计感知到命令输出的总耗时 |

应与相同数据、相近计算预算的直接策略进行对照，并单独去掉未来监督做消融。若只报告视频质量，无法判断世界建模是否真正帮助机器人控制。

进一步阅读：[Diffusion Policy](https://diffusion-policy.cs.columbia.edu/)，用于理解连续动作生成这一基础组件；它本身不能直接当作联合世界—动作模型的同义词。


# 扩展图解：接口、机制与实验

## 1. 预测模型与策略的区别

![预测模型与策略的区别](/wam-factor.png)

策略回答“下一步做什么”，世界模型回答“这样做会怎样”。联合世界—动作建模可以同时学习两者，但仍需说明条件分布：$p(a\mid o)$、$p(o'\mid o,a)$ 与 $p(a,o'\mid o)$ 不是同一个对象。

图中的箭头决定因果解释。若模型只预测未来视频而没有动作条件，它可能学到常见运动，却不能直接支持对不同候选动作的反事实比较。

## 2. 候选动作与模型预测控制

![候选动作与模型预测控制](/wam-mpc.png)

图中 8.2、6.5、3.1 仅为候选评分的教学示例，不是实测成绩；本例约定分数越高越好，若使用代价函数则取最小值。

模型预测控制生成候选动作序列，用世界模型估计后果，再按目标和约束评分。执行通常只取前一小段，随后重新观测并规划，以减轻模型误差。

图中最高分候选不一定真实最好，因为评分和预测都可能出错。候选搜索越强，越可能利用模型漏洞；因此需要约束动作范围、监测不确定性，并用真实环境验证最终收益。

## 3. 不确定性与接触边界

![不确定性与接触边界](/wam-uncertainty.png)

不确定性既可能来自观测噪声和遮挡，也可能来自训练覆盖不足。接触事件尤其敏感：微小位姿差异可能决定抓住、滑落或碰撞，平滑像素预测未必准确表达这种分叉。

图中的多个未来不是装饰性多样性。评估要检查它们是否覆盖真实结果、概率是否校准，以及策略是否在不确定区域采取更稳健的动作。单次清晰预测不能作为确定性的证明。

## 4. 如何评估世界动作模型

![如何评估世界动作模型](/wam-eval.png)

评测分三层：视觉层检查外观与时间一致性；状态层检查几何、接触和物体持久性；控制层检查真实闭环成功率、耗时与干预。不同层回答不同问题，不能互相替代。

图中一段逼真视频可能仍违反动作方向或物理约束。建议加入动作交换测试：保持观测不变，改变候选动作，检查预测后果是否产生正确变化；再与不使用世界模型的策略做资源匹配对照。
