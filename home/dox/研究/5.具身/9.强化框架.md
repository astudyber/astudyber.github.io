# 1. 强化学习：让策略从反馈中改进

## 1.1 概览

模仿学习用示范告诉机器人“怎样做”；强化学习利用奖励与交互结果学习“哪些行为更有价值”。实际机器人常先做行为克隆，再结合固定数据、仿真交互或真机反馈改进。资料核对日期：2026-09-21。

# 2. 基本量与学习信号

## 2.1 状态、动作与回报

策略记为 $\pi(a \mid o)$，环境在动作后返回新观测与奖励。折扣回报可写作 $G_t=\sum_{k=0}^{T-t-1}\gamma^k r_{t+k}$。机器人通常只获得部分观测，历史图像、状态估计或记忆可帮助缓解信息不足。

价值 $V(o)$ 估计当前情境下的预期回报；动作价值 $Q(o,a)$ 比较具体动作；优势 $A(o,a)=Q(o,a)-V(o)$ 表示相对于基准的好坏。只有在相应定义和估计假设下，这些量才可直接比较。

## 2.2 终止和截断

任务完成或不可恢复失败属于环境定义的结束；达到采样时间上限可能只是截断。构造 TD 目标时是否继续 bootstrap 取决于真实终止语义，不能看到 episode 结束就统一把未来价值置零。参见 [Gymnasium 的终止与截断说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)。

# 3. 范式选择

| 方法或范式 | 数据条件 | 核心思路 | 主要限制 |
| --- | --- | --- | --- |
| BC | 专家示范 | 监督拟合动作 | 容易遇到分布偏移 |
| DAgger | 可查询专家 | 收集策略访问状态上的纠正标签 | 需要专家标注能力 |
| IQL | 固定离线轨迹 | 学习价值并提取策略 | 受数据覆盖限制 |
| SAC | 可持续交互，经验回放 | 熵正则的离策略学习 | 需要可靠交互与奖励 |
| PPO | 持续采集当前策略轨迹 | 限制策略更新幅度 | 样本成本可能较高 |

算法依据分别见 [DAgger](https://arxiv.org/abs/1011.0686)、[IQL](https://arxiv.org/abs/2110.06169)、[SAC](https://arxiv.org/abs/1812.05905)、[PPO](https://arxiv.org/abs/1707.06347)。表格用于定位方法，不能替代各论文的目标函数和实现条件。

# 4. 奖励设计：从任务目标出发

## 4.1 抓放任务的教学奖励

一种可解释的设计是：任务完成给主要奖励，持续耗时给小代价，碰撞或掉落有明确惩罚，接近目标等进展项仅用于辅助。具体权重需要实验决定。

如果只奖励“夹爪靠近杯子”，机器人可能停在杯旁而不抓取；若反复奖励触碰托盘，可能学会来回接触刷分。这就是目标代理与真实任务之间的偏差。

## 4.2 奖励升高不等于任务变好

至少同时看最终成功率、完成时间、接管次数和失败类型。区分训练奖励与独立成功判定，避免用同一有缺陷的信号证明策略有效。

# 5. 大模型策略的后训练

## 5.1 π*0.6 与 RECAP

RECAP 将示范、专家纠正和自主经验结合，通过价值估计与优势条件化改进 VLA。π0.6 是基座名称，π*0.6 指相应强化学习路线得到的模型，两者不宜混写。参见 [Physical Intelligence 官方说明](https://www.pi.website/blog/pistar06)。

学习重点不是把所有失败样本删除，而是给行为提供可区分的质量信息。价值估计若把“暂时绕路但最终成功”误判为坏动作，就可能损伤长程策略，因此需要查看完整轨迹。

## 5.2 世界模型与反馈

世界模型可以提供预测信息或辅助训练，但模型内获得的高奖励仍需真机确认。预测误差可能被策略利用，因此应缩短不可靠的预测范围、对照真实数据，并保留独立评测。相关研究见 [GigaBrain-0.5M*](https://arxiv.org/abs/2602.12099)。

# 6. 一次可审计的实验迭代

1. 固定行为克隆基线，保存原始检查点与独立评测。
2. 采集策略实际访问的状态，记录策略命令、人工命令和最终执行命令。
3. 标注成功、失败、超时与接管，不混淆控制来源。
4. 按算法训练价值或策略，并检查分组统计。
5. 在固定评测集上比较，再增加新的场景压力测试。

若采用人工接管，只保存接管后的漂亮动作不够；要保留接管前的观测和错误状态，才能研究恢复。模型更新和数据版本必须成对记录。

# 7. 诊断与评测

| 现象 | 可能原因 | 下一步检查 |
| --- | --- | --- |
| Q 值持续增大，成功率下降 | 价值过估计或奖励尺度错误 | 回报分布、终止掩码 |
| 奖励上升，任务未完成 | 奖励投机 | 回放高奖励轨迹 |
| 训练场景成功，换场景失败 | 覆盖不足或视觉捷径 | 场景分组评测 |
| 纠正后总重复同类错误 | 接管标签错位 | 实际执行命令与观测时间 |
| 成功但越来越慢 | 时间成本设计不当 | 成功吞吐量与等待时长 |

真机训练还需要独立的动作边界与停止机制，以免算法探索超出硬件可用范围。它属于实验系统的一部分，不能由奖励惩罚来替代。

推荐阅读顺序：BC 与分布偏移 → DAgger → 一个连续控制 RL 算法 → 离线 RL → VLA 后训练。先完成可复现的小任务，再扩展模型规模和任务长度。
