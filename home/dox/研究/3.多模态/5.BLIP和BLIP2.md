# BLIP 与 BLIP-2：数据自举与查询桥接

> 原创机制图解；架构示意不替代具体版本配置，算例不是实测成绩。资料核对：2026-09-22。

## 1. BLIP 的统一训练视角

![BLIP 的统一训练视角](/blip-med.png)

### 1.1 理解与生成的不同计算需求

BLIP 将图文对齐、匹配和描述生成放入统一预训练框架。图文对比需要可独立编码的表示，匹配需要跨模态交互，生成需要因果文本解码。其多模态编码器—解码器设计通过不同注意力配置支持这些需求，并共享部分参数。

图中任务卡表示监督职责，不是把三个损失依次用在一个回答上的流水线。阅读实现时应核对哪些层共享、哪些注意力被启用，以及每个目标可见哪些输入。

### 1.2 多目标配比

概念上可写 $L=\lambda_cL_{ITC}+\lambda_mL_{ITM}+\lambda_gL_{LM}$。权重、负样本采样和数据清洗都会影响效果；一个加权和公式并不足以复现训练。生成能力好也不保证匹配分数已校准。

## 2. CapFilt 数据自举

![CapFilt 数据自举](/blip-capfilt.png)

### 2.1 生成候选，再筛选

CapFilt 使用描述生成器为图像产生候选文本，并用过滤器去除与图像不一致的描述；原网络描述与合成描述都需要经过质量判断。目的不是把网络噪声简单替换为模型输出，而是改善可用图文配对。

图中两条描述来源汇入过滤器。生成器可能补充原文遗漏，也可能幻觉物体；过滤器同样可能漏检。多个模型一致不必然代表事实正确，尤其当它们共享训练偏差时。

### 2.2 如何审查数据自举

抽样比较原描述、合成描述和最终保留文本，按存在性、属性、数量和关系标注错误。记录过滤通过率与不同类别覆盖，不只报告最终规模。

如果过滤器倾向保留容易图像，清洗后平均质量提高的同时，长尾覆盖也可能下降。应同时观察噪声与多样性，而不是以通过率最大化作为目标。

## 3. BLIP-2 与 Q-Former

![BLIP-2 与 Q-Former](/blip2-query.png)

### 3.1 查询桥接两个冻结模型

BLIP-2 用可训练 Q-Former 连接冻结视觉编码器与冻结大语言模型。可学习查询通过交叉注意力读取视觉特征，再把查询输出投影到语言模型输入空间。图中的锁只表示相应参数冻结，不代表这些模块不执行计算。

视觉特征是 N×dᵥ，查询输出是 M×d_q；通常 M 小于原视觉位置数，形成信息瓶颈。投影改变维度，查询机制改变信息聚合与数量，两者职责不同。

### 3.2 冻结与梯度

冻结语言模型参数时，为了训练它前面的连接器，仍可能需要反向经过语言模型计算图。把整个冻结语言模型包进 no_grad 会切断这条路径。冻结节省的主要是参数梯度和优化器状态，不等于省去全部激活与前向成本。

## 4. 两阶段训练与信息瓶颈

![两阶段训练与信息瓶颈](/blip2-stages.png)

### 4.1 先学习表示，再接入语言生成

BLIP-2 第一阶段学习视觉语言表示，第二阶段学习与冻结语言模型的生成接口。图示是原方法的训练思路；不同语言骨干、检查点和后续微调可能采用不同输入与输出设置。

通过多目标与查询交互，模型尝试提取语言相关视觉信息。但“相关”取决于训练任务；细小 OCR、精确计数或空间关系可能在压缩中损失。

### 4.2 瓶颈怎么测

固定视觉编码器和语言模型，只改变查询数量，比较任务质量、显存与延迟。若整体描述不变而小字读取改善，说明更细任务可能受压缩限制；若均无改善，应检查视觉分辨率或监督。

增加查询并不是无成本提升，后续语言模型会处理更多前缀位置。应按完整系统成本比较，而非只统计 Q-Former 参数量。

## 5. 推理、对照与适用边界

![推理、对照与适用边界](/blip-eval.png)

### 5.1 检查点与任务接口

BLIP 可用于描述和问答等任务，BLIP-2 的语言骨干可能是 decoder-only 或 encoder-decoder。processor、prompt 格式和生成结果裁切规则必须匹配检查点，不能统一按输入长度删除所有输出前缀。

图中对照表用于实验设计，不能视为论文已证明哪种连接器在所有场景最优。直接投影、查询压缩和更高 token 预算都应在受控设置下比较。

### 5.2 失败分层

先保存处理后的图像，判断视觉证据是否可见；再检查提问与模板是否正确；最后比较连接器和语言生成。若模型在无图条件下仍生成相同答案，应进一步评估语言先验影响。

回答拒绝、重复、过早结束可能来自模板或生成参数，不一定是视觉表征问题。把数据、接口和模型错误分层记录，排查效率更高。

## 6. 算例与实践

### 6.1 压缩量不等于信息保真

假设视觉位置从 256 压到 32，位置数减少八倍；但每个查询是多个视觉位置的可学习聚合，不是简单保留每八个位置中的一个。若输出维度相同，后续前缀存储减少；视觉编码器的原始计算仍然存在。

### 6.2 数据自举小实验

选 50 张覆盖常见与长尾场景的图，保留原始描述、生成描述和人工核验。按类别统计错误率与通过率，并检查过滤掉的样本。人工标注用作评估时，不应反复拿同一批数据调过滤阈值后还报告独立效果。
