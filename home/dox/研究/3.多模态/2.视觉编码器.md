# 视觉编码器：从像素到视觉 token

> 原创机制图解；架构示意不替代具体版本配置，算例不是实测成绩。资料核对：2026-09-22。

## 1. 预处理与坐标

![预处理与坐标](/vision-preprocess.png)

### 1.1 模型看到的是处理后的图

读取图像后需明确颜色通道、取值范围、尺寸、插值方式和归一化统计。RGB 与 BGR、0–255 与 0–1 不是无关细节；即使张量形状正确，输入分布也可能完全不匹配预训练。

图中缩放、裁剪和补边必须记录几何变换。若点先按比例 s 缩放，再加偏移 (a,b)，新坐标为 (sx+a,sy+b)，逆变换必须对应同一路径。不同轴缩放率不同时分别使用 sₓ、sᵧ。

### 1.2 训练增强与推理处理

训练可以随机裁剪或改变颜色，但标签和任务语义必须同步。OCR 的强裁剪可能删掉答案，水平翻转会改变左右关系，文档旋转会改变阅读顺序。推理通常使用确定处理以便复现，若采用多裁剪，需计入成本并说明聚合方式。

## 2. CNN 与 ViT

![CNN 与 ViT](/vision-patches.png)

### 2.1 从局部卷积到 patch 序列

CNN 通过局部感受野和共享权重提取特征，逐层聚合空间信息。ViT 将图像分为 P×P patch，展平并线性投影；若 H、W 可整除 P，基础 patch 数为 $N=(H/P)(W/P)$，位置编码补充空间次序。

图中投影改变每个 patch 的特征维度，并不自动减少 patch 数。分类 token、池化和下采样属于额外设计；不同编码器输出形状不能只凭名称猜测。

### 2.2 局部信息与全局信息

全局池化向量适合检索和分类，却可能丢失定位所需的空间差异。密集任务通常读取 patch 特征或多尺度特征。最后一层未必最适合所有任务，中间层可能保留更多局部细节。

注意力可以聚合远处位置，但位置与纹理信息是否保留仍取决于训练目标。视觉骨干更大，不保证文字、小目标或域外数据都提升。

## 3. 预训练目标与特征性质

![预训练目标与特征性质](/vision-objectives.png)

### 3.1 不同目标塑造不同表示

监督分类要求区分类别，图文对比要求匹配语言描述，掩码重建要求恢复缺失内容，自蒸馏要求学生与教师表示一致。这些信号对不变性和局部细节的要求不同。

图中四类监督是概念划分，具体模型可能组合多个目标。重建像素不必然学到语义，文本对齐不必然保留精确几何；因此选编码器要看下游需要什么信息。

### 3.2 现代视觉表征

DINOv3 属于自监督视觉表征路线，强调可用于多种视觉任务的特征；SigLIP 2 在视觉语言编码中扩展语义、定位与密集特征能力。二者不是同一种训练目标，也不是可无条件互换的输入接口。

迁移时固定分辨率和读取层，比较冻结探测与微调结果。若冻结探测差而微调后好，可能说明信息存在但未线性可分；若某类细节始终缺失，应回查处理分辨率和训练监督。

## 4. 多尺度与高分辨率

![多尺度与高分辨率](/vision-resolution.png)

### 4.1 全局与局部的互补

整体缩略图保存布局，局部切片提供小字和细粒度信息。切片之间应保留顺序与位置信息，否则语言模型难以把局部内容放回原图。边界重叠还会重复物体，计数时尤其容易出错。

图中多个切片并不意味着简单增加样本数；对同一问题，它们组成同一个视觉上下文。切片数量、每片 token 数与连接器压缩共同决定最终预算。

### 4.2 分辨率不是越大越好

提高分辨率可能改善细节，但也增加显存、传输和注意力计算。原图本来模糊时，插值放大不能创造真实信息；若关键区域已被裁掉，更大模型也无法恢复证据。

比较分辨率策略时控制语言骨干与输出长度，同时报告图像处理耗时和视觉 token 数。只比较 GPU 前向时间可能漏掉 CPU 解码瓶颈。

## 5. 特征选择与迁移诊断

![特征选择与迁移诊断](/vision-transfer.png)

### 5.1 三种迁移方式

冻结骨干只训练线性头，成本低且便于诊断表示；部分解冻允许局部适应；全量微调能力强但更依赖数据和正则化。冻结参数不等于关闭所有反向路径：若前面仍有可训练模块，不能随意套 no_grad。

图中评估按语义、定位、OCR 和域外表现分组。平均分可能掩盖某种能力下降，尤其在替换连接器或读取层之后。

### 5.2 一个接口合同

记录输入 shape、dtype、颜色与归一化，输出 token 数、维度、特殊 token、空间网格和读取层。检查点与 processor 作为整体版本保存。连接器输入维度相同，仅说明矩阵能相乘，不说明特征分布可直接替换。

## 6. 算例与实践

### 6.1 Patch 算例

224×224 图像、patch=16 时，基础网格为 14×14，共 196 个 patch；448×448 则为 28×28，共 784 个。若直接全局自注意，token 数四倍，分数矩阵元素十六倍。加入 CLS token 后分别为 197 和 785，应按真实实现计算。

### 6.2 诊断实验

准备分类、小字读取和定位三个小任务。固定样本与训练预算，比较全局向量、末层 patch、中间层 patch；再只改变分辨率。保存失败样本的实际处理后图像，确认模型究竟看到了什么。
