# VLM 简介：对齐、融合与生成

> 原创机制图解；架构示意不替代具体版本配置，算例不是实测成绩。资料核对：2026-09-22。

## 1. 任务与输入输出

![任务与输入输出](/vlm-tasks.png)

### 1.1 先定义任务，再讨论模型

视觉语言模型把图像、视频与文本放入同一学习系统，但“多模态能力”不是一个单一指标。检索返回相似度排序，问答生成文本，定位返回坐标，视频理解还涉及事件时间。不同输出需要不同监督与评估。

图中四类任务共享视觉输入，却不共享完整正确性标准。问答答对物体名称不代表能定位它；定位框准确也不代表理解物体关系。研究笔记应写明输入是否完整、是否允许外部检索以及输出格式。

### 1.2 条件生成

生成式 VLM 建模 $p(y\mid I,q)=\prod_t p(y_t\mid I,q,y_{<t})$，I 是视觉输入，q 是问题，y 是回答。生成概率高说明它符合模型学习到的条件分布，不等于它被图像事实支持。

多图任务还需保留图像与指代的对应关系；视频任务需要时序。把多张图简单打乱后仍问“第二张”或“之前”，会让数据本身失去一致语义。

## 2. 三种基本架构

![三种基本架构](/vlm-architectures.png)

### 2.1 双塔、融合与生成

双塔分别编码图像和文本，适合预计算向量与大规模检索；融合编码器让两模态细粒度交互，适合匹配和重排；生成架构把视觉表示送入语言模型，输出开放文本。三者的成本、缓存方式与输出能力不同。

图中三行是架构家族，不是所有模型必须经过的三阶段。双塔的图像向量可以离线缓存，融合模型通常需要对每个图文对重新计算；开放生成又增加逐 token 解码成本。

### 2.2 信息瓶颈在哪

视觉编码器可能丢掉小字，连接器可能压缩局部细节，语言模型可能忽略视觉信息。最终答错不能全部归因于“语言模型不够大”。通过原图分辨率、视觉 token 数、连接器形式和文本问题的受控变化，才能定位瓶颈。

## 3. 对齐与训练信号

![对齐与训练信号](/vlm-objectives.png)

### 3.1 三种常见监督

图文对比学习把配对样本拉近、非配对样本区分；图文匹配预测一对是否一致；条件语言建模预测下一词。它们分别强调全局对齐、跨模态判断和文本生成，不能仅凭共享数据就认为目标相同。

对比目标可写为 $-\log[\exp(s_{ii}/\tau)/\sum_j\exp(s_{ij}/\tau)]$。批内其他描述可能也正确，形成假负样本；图像中未被描述的物体并不是负标签。

### 3.2 数据比标签数量更复杂

网络描述常只覆盖显著内容，包含水印、语气和上下文。OCR、空间关系、计数和细粒度属性需要更针对性的监督。合成指令可以扩充表达，却也会放大教师模型的偏差。

数据混合比例决定训练期间不同能力被看到多少次。报告总样本数之外，还应说明语言、分辨率、任务类型、去重方式和评测集重叠检查。

## 4. 数据、幻觉与评估

![数据、幻觉与评估](/vlm-grounding.png)

### 4.1 幻觉是证据不足下的生成

模型可能依赖常见共现关系回答，而不是读取当前图像。流畅和详细会增强可信感，却不能作为视觉依据。评估应拆分物体存在性、属性、数量、关系和文本读取，记录证据与错误类型。

图中原图、关键区域遮挡和背景替换构成不同反事实对照。如果删掉关键物体后答案完全不变，说明值得进一步检查视觉依赖；但单次不变也可能因为问题本来不需要那一区域。

### 4.2 指标与判分

封闭选择题便于自动评分，却可能受选项与语言偏差影响；开放回答覆盖更广，但裁判模型可能有偏好。坐标任务要明确像素或归一化单位，视频任务要明确秒或帧索引。

同时报告准确性、拒答、视觉 token 数、首字延迟和完整响应时间。对图中看不清的信息允许表达不确定，并检验拒答是否集中于困难样本，而不是简单回避所有问题。

## 5. 现代方向与实验设计

![现代方向与实验设计](/vlm-frontier.png)

### 5.1 从单图语义走向密集与时序信息

高分辨率与动态切片为 OCR、小物体和文档提供更多可见细节，代价是更多 token。视频把时间采样也变成信息瓶颈：少采帧可能漏掉关键事件，多采帧又增加预算。

SigLIP 2、DINOv3 等视觉表征研究关注更广泛的语义或密集特征用途；Qwen3-VL 等生成模型扩展多图、视频与长上下文。它们解决的层次不同，不能把编码器改进直接等同于端到端问答提升。

### 5.2 工具与检索

检索增强提供外部资料，裁剪或放大工具改变视觉输入，程序工具计算数量或几何量。新增工具后应把调用次数、工具错误和额外上下文计入系统评估。

研究扩展截至 2026-09-22；本目录按机制组织，具体版本以论文和官方配置为准，不用不断变化的排行榜代替可复现实验。

## 6. 算例与实践

### 6.1 用一个场景拆解能力

拍摄桌上两个杯子和一本书，分别询问“有哪些物体”“杯子有几个”“左侧杯子是什么颜色”“书上的文字”“杯子在书的哪一侧”。这些问题依次测试识别、计数、属性绑定、OCR 和关系。

固定问题后改变背景，再固定背景改变杯子颜色。比较答案是否随相关因素变化、对无关因素保持稳定。所有修改记录下来，不能只展示最成功的一张。

### 6.2 预算算例

假设图像每边可分为 16 个 patch，则有 256 个视觉位置；每边分辨率翻倍且 patch 大小不变时变为 1024。若某层对这些位置做全局注意力，分数元素从 256² 变为 1024²，增长 16 倍。实际系统可能压缩或分块，必须以实际 token 和内核为准。
