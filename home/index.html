VLMVLP 实验室 · 2025.07 — 2025.12

多模态大模型微调与强化学习

项目目标：面向图像美学感知与交通事故视频问答，探索多模态模型从数据构建、监督微调到偏好强化学习的完整后训练流程。

具体工作：基于 Qwen3-VL-8B 与 Llama-Factory 完成 ShareGPT 格式数据准备、LoRA 矩阵和权重超参数配置，采用冻结视觉编码器、微调语言模型的策略训练；将 LoRA 扩展到 ViT 层，加入文本增强、任务导向复合矩阵和审美提示词，并编写批量推理、评价模型 Top-1 筛选及测评脚本。针对交通事故 VQA，使用 Coze 多智能体生成分层 CoT/QA 标注，人工校验后进行 SFT 与 GRPO 训练。

结果：美学数据集由 8,400 个 QA 扩充到 26,880 个，三项核心指标提升 2%—9%；完成 BLEU-2、ROUGE-2、tIoU@0.5、Acc 等指标实现，并对比评测 LLaVA、Qwen、VideoLLaMA 等 7 种开源模型。

VLA吉利研究院 · 2026.03 — 2026.08

机械臂 VLA 算法研发

项目目标：参与机械臂 VLA 模型从数据采集、动作控制、仿真验证到真机部署的完整研发流程，完成 piperaio 硬件启动、置零标定与 CAN 接口配置。

仿真与监督微调：基于 PI05 + QDMD 引入 Moment Matching，以 QGF 修正 Flow Matching 速度场，结合 CPS 采样与 DMD few-step 推理，将 Libero_10 长程任务成功率由 92.6% 提升至 96%，单步推理由 150ms 降至 40ms。基于 JAX 搭建 openPi 多任务 SFT 基线，完成插花、插网线、插吸管、夹水杯、夹水果、清扫垃圾、放抽屉等任务的数据清洗、全量微调与多位置泛化测试。

真机强化学习：在 EXPO-FT 框架中融合 IQL、QGF、best-of-N 候选采样和 Human-in-the-Loop DAgger，对比 online/offline、on-policy/off-policy 训练范式；通过 replay buffer 将数据利用率提升 3—5 倍，真机插花任务成功率由 SFT 基线 50% 提升至 70%。

AGENT吉利研究院 / 区块链产业发展研究会

车载主动交互与 RAG 智能体

车载 Agent 目标：解决车载主动交互中的视觉理解不足、用户意图泛化困难与车控指令冲突问题，设计 VLM、LLM 与多 Agent 协作的场景决策系统。系统接收车端图片、多帧数据、实时车辆信号、用户画像和历史对话，输出可执行的车控指令列表。

决策链路：“一句话场景泛化”链路融合用户语句、历史对话、视觉 Caption 与车辆信号，完成自定义场景识别和车控决策；“主动交互”链路由 VLM 感知、舒适/安全/情绪分类、子 Agent 并行决策、结果合并及安全边界校验组成。

工程结果：采用 AWQ-INT4 量化、关键帧筛选、车辆信号前置过滤、子 Agent 并行和功能渐进式披露，准确率提升约 9%，平均时延增幅约 4.5%，P90 时延增幅约 2.5%，并使用 FastAPI 完成服务化部署。此前还负责 Lepton + LlamaIndex 私有知识库 RAG，完成文档向量化、索引建立、语义检索和 GPT API 问答链路。
