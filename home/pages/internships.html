01

机械臂 VLA 全链路研发

Sim → SFT → RL

深度参与机械臂 VLA 模型从数据采集、清洗、动作调控到训练部署的完整流程，完成 piperaio 机械臂硬件启动、置零标定与 CAN 接口配置，并以 Libero 仿真打通算法训练到真机落地的闭环。

  • PI05 + QDMD 仿真强化学习：引入 Moment Matching 机制，以 QGF 修正 Flow Matching 速度场，结合 CPS 采样与 DMD few-step 推理，将 Libero_10 长程任务成功率由 92.6% 提升至 96%，单步推理由 150ms 降至 40ms。
  • openPi 真机 SFT：基于 JAX 搭建多任务监督微调基线，完成插花、插网线、插吸管、夹水杯、夹水果、清扫垃圾、放抽屉等任务的数据清洗、全量参数微调与多位置泛化测试；插花特定位置成功率超过 90%。
  • EXPO-FT 真机强化学习：融合 IQL、QGF 与 best-of-N 候选采样，对比 online/offline、on-policy/off-policy 范式；使用 replay buffer 提升数据利用率 3—5 倍，并通过 Human-in-the-Loop DAgger 加速收敛，真机插花成功率由 SFT 基线 50% 提升至 70%。
02

车载主动交互与一句话场景泛化

VLM + LLM + Multi-Agent

面向车载主动交互中视觉理解不足、用户意图泛化困难和车控指令冲突等问题，设计场景感知、智能介入与车控决策系统。系统融合车端图片、多帧数据、实时车辆信号、用户画像和历史对话，输出可执行的车控指令列表。

  • 一句话场景泛化链路：将用户语句、历史对话、视觉 Caption 与车辆信号统一编排，完成自定义场景识别、意图理解与车控决策。
  • 主动交互链路：通过 VLM 感知、舒适/安全/情绪分类、子 Agent 并行决策、结果合并及安全边界校验，实现车内主动介入。
  • 性能与部署：采用 AWQ-INT4 量化、关键帧筛选、子 Agent 并行处理、车辆信号前置过滤和功能渐进式披露，准确率提升约 9%；平均时延增幅约 4.5%，P90 时延增幅约 2.5%，并以 FastAPI 完成服务化部署。
